# @model: Selector
Does this change add or modify program logic (conditions, loops, calculations, state changes) rather than only documentation, formatting or configuration comments?
# @model: Prompt
Read the change against its title and description. Look for logic that does not do what the
author intended: inverted or missing conditions, off-by-one bounds, wrong operator precedence,
an early return that skips required work, state updated in the wrong order, or a new branch that
the existing callers cannot reach. Report only defects you can point at in the diff, with the
line that is wrong as the anchor. Do not report style.
# @model: Examples
Bad: `if (items.Count > 0 && items.Count < max)` where the description says "up to and including max".
Good: `if (items.Count > 0 && items.Count <= max)`.
# @humans: Why this check exists
A general correctness pass so every change gets at least one reviewer reading the logic itself.
# @maintainers: Rationale
Built-in seed check, used only when neither the instance nor the repo configures checks.
