# @model: Selector
Does this change alter behaviour that a test could check, rather than only documentation or formatting?
# @model: Prompt
Check that behaviour the change adds or fixes is covered by a test in the change that would fail
without it. Look for a bug fix with no regression test, a new branch with no test reaching it, or a
test that asserts nothing about the changed behaviour. Do not ask for tests of trivial code. Anchor
the finding on the changed line that is untested.
# @model: Examples
Bad: a fix to `if (count >= max)` with no test at `count == max`.
Good: a test that sets `count` to `max` and asserts the new outcome.
# @humans: Why this check exists
A fix without a regression test is likely to be undone by the next change.
