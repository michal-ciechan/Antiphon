## Seams and defaults

- **Field:** a new `HostStatsCache.Latest(hostId)` returns a `HostStatsSample(Snapshot, ObservedAt)`, or null when no sample was ever recorded. `ObservedAt` is the server time when the cache first saw that sample's `At`. A runner that keeps repeating one stale sample therefore goes stale, and a later `RecordFailure` keeps the old time.
- **Builder:** `AttentionService.BuildWorkspaceDiskLowItems(now)` in `AttentionService.Alarms.cs`. It is called right after `BuildJournalStaleItems` and is computed on every read, so nothing new is persisted and no notifier, channel or sink is added. The row is kind `WorkspaceDiskLow = 65`, Warning, `ConditionKey workspace-disk-low:<runnerId>`, action OpenDrawer, and `SinceUtc` set to ObservedAt.
- **Evidence:** `runner=..; path=/work; usedPercent=..; threshold=85; freeBytes=..; totalBytes=..; observedAt=..; retention=<Off|DryRun|Execute>`.
- **Retention mode** comes from `IConfiguration`: `RunnerWorktreeRetention:Enabled` and `:Execute`. Anything other than a parsed `true` for Enabled gives `Off`. S1's settings type is not referenced.
- **Threshold (S-7):** `Int128` compare `100*(Total-Free) >= UsedPercent*Total`. The design said checked `long`; `Int128` is exact for every long, so the feed cannot throw on overflow. A reading with `Total <= 0`, `Free < 0` or `Free > Total` raises nothing.
- **Settings:** new `WorkspaceDiskAlarmSettings` bound to the `WorkspaceDiskAlarm` section.
  - Code defaults: Enabled=true, UsedPercent=85, SampleFreshMinutes=15, and an **empty** Runners map. A config-bound dictionary merges keys, so a code default could never be removed by an operator.
  - `server/appsettings.json` sets `{"server2": "/work"}`. The server2 runner compose already reports `/work` and `/state` (`SessionRunner__HostStats__Volumes__0/1`).
- **Validator** (`WorkspaceDiskAlarmSettingsValidator`, ValidateOnStart): UsedPercent must be 50..99 and SampleFreshMinutes 1..1440. It refuses a blank runner id, the desktop runner, and a blank or non-absolute (`/`-less) path.
- **D-11:** the builder also skips the desktop id even when it is listed (defence in depth).
- **Shared files** (additive only): `Program.cs` gets one options registration beside `Alarms`; `appsettings.json` gets one section beside `Alarms`. `AttentionService` gains 3 optional trailing constructor parameters (`hostStats`, `workspaceDiskAlarm`, `configuration`), so all 43 existing test constructions are unchanged.
- No csproj or pins edits, and no land-graph change.
