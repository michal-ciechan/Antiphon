### C1338_Retire_temp_dry_run_lists_exactly_the_temp_volumes

Old hazard: the dry-run names exactly the four temp volumes, removes nothing, writes no journal, and does not stop, rm, create, start, run, or volume-rm. It expected the old order (work, tmp, dind, state) and `auditPending=true`.

New: the same non-mutation checks, with `run` removed from the blanket ban and replaced by the helper constraint already used by `C1008_Recycle_dry_run_never_mutates` (`--rm`, `--cap-drop ALL`, a readonly mount). Order is state, dind, tmp, work. Preview must be `auditPending=false` and carry the Ready marker. New witness: after that Ready preview, `C1609_FIXTURE_APPLY_GATE=off` must exit 2 with `DIAGNOSIS=apply-gate-off`, remove nothing, write no journal, and issue no stop, rm, create, start, run, or volume rm.

The old `run` ban cannot pass a correct CARD-1609 preview, because the preview now starts the read-only content helper. The replacement still forbids every mutating verb and constrains every run. The gate-off witness is new. Not weakened to pass.

### C1008_Recycle_dry_run_never_mutates

### C1008_Retire_temp_rechecks_absence_and_retirement

Old hazard: a successful retire removes exactly four volumes; host-predicate failures, `ps-error`, `counterpart`, and `down-retains-volume` exit 2 and remove nothing; an exited state-init stays; null refuses and integer zero accepts.

The hazard that replaced it is a volume rm that exits 0 and leaves the volume. The absence check at :9505 is what refuses that.

New: the accepted apply still requires four removals, and now also forbids any compose down. An apply with the token and no Ready preview must exit 2 with `RecycleGitAuditUnknown reason=preview-required`, remove nothing, and not stop or rm. The predicate, `ps-error`, `counterpart`, state-init, and null/zero cases remain. `rm-retains-volume` must exit 2, print `RecycleRemoveFailed`, remove nothing, and issue exactly one `volume rm`. That is the same "do not trust a successful delete" hazard, on the call the script actually makes, plus the new preview gate.
