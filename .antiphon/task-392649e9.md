## D-2 closed

- Failed tracking write or fast root exit (both after native intent): `ReleaseFailedLinuxAsync`, then a disposition, then a fresh TTL.
- Failure before native intent: the existing linger runs immediately.
- Shim or cgroup creation failure with a missing tree: Unknown, no disposition, the host is retained. This is the plan's "permanent Unknown, operator-owned" row, not a defect.
