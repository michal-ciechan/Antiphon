## Check 2: A-1 create-time mode

- `WriteTemp` (`ClaudeProjectTrust.cs:248-271`) opens the per-call GUID temp with `FileMode.Create` and `UnixCreateMode = File.GetUnixFileMode(source)` before writing any bytes. The temp name never exists beforehand, so `open(O_CREAT, srcMode)` applies, and the umask can only clear bits.
  The temp therefore never holds secret content at a mode more permissive than the source. `CopyUnixMode` then restores any bits the umask removed.
- Windows: the `OperatingSystem.IsWindows()` guard keeps `UnixCreateMode` null and skips `GetUnixFileMode`, so Windows takes the same `FileStream` path as before with no Unix API and no exception. The written bytes are identical (`Utf8NoBom`, no BOM).
- Failure cleanup: the `finally` in `WriteAtomic` deletes the temp on every attempt and for every exception type. A source that vanishes surfaces as `FileNotFoundException`, an `IOException`, which is retried. Any other exception becomes `Failed` through `Seed`'s outer catch.
