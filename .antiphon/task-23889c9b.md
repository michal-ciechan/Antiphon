## Residual windows (exact)

- Hash → unlink (Linux): a write through a descriptor opened before the per-entry hash, or a rename-replace of
  the name between the same-inode stat and `unlinkat`, is not seen; Linux has no unlink-if-inode. Windows holds the
  entry's handle without delete sharing, so the name cannot be replaced, but a write through another open handle
  is likewise not seen.
- A name created after a directory's final listing and before its `rmdir` is never unlinked: the `rmdir` fails,
  the pass is `worktree_removal_incomplete`, and the retry holds `set_aside_content_changed`.
- Marker: a repository marker created between the last per-entry check and that entry's unlink costs at most
  that one leaf entry.
- Retained evidence: the copy is checked by `CustodyOf` immediately before the delete; removal or change of the
  retention copy by another actor during the walk is not re-checked. A retention prune between passes holds the
  set-aside (`evidence_retained_missing`) until an operator acts.
- Disposable (CARD-0665 allowlisted ignored) entries are bound by name and kind only; their bytes can change.
- Identity: an inode reused after the original directory was removed matches only within one coarse clock tick
  (~4 ms observed) or on a file system without birth time; custody still requires every non-disposable entry to
  match by name, kind and hash, and a restored replacement is re-inspected from scratch.
- Restoring a held remainder is manual: move `<common>/antiphon/worktree-removal/<key>.admin` back to the
  registration's admin path and the set-aside back to the worktree path (the witness does exactly this).
- Windows: the walker's per-directory and per-entry receipt checks and `WindowsDirectoryIdentity`/`WindowsRegularFileHash`
  have no native witness (desktop forbidden while qualification b19a9880 runs). The walk witnesses are Linux-gated
  skips on Windows; the Windows locked-file cases (`C665_LockedFileMidDeleteResumesOnLaterPass` ×2, `C721_HeldHandleDuringCleanupStaysRegisteredOrRecorded`) and the junction cases stay skipped on Linux.
