## Defects

### D-1: gate calls resolve by name, not by the binding or execution the compiler uses
- **Where:**
  - `scripts/lib/linux-only-gate-witness.cs:182-199` (`GateContext.Resolve`), used by `IsDirectCall` :473-494, `IsHelperReturnIf` :428-439, `IsDeconstruct` :527-564 and `IsParsedProbe` :566-590.
- **Failure:** X01, X02, X03, X04, X09b, X17, X18, X19 and X20.
- **Why:**
  - Resolution ignores local functions, `using` aliases, fields and parameters that shadow a type, `[Conditional]`, bodiless `partial` declarations, and `async`/iterator bodies whose first statement never runs synchronously.
  - X18 alone silently disables the gate in every row that uses `NativeLinuxGate.Require`.
- **Fix:** do not extend the closed list. See the recommendation below.

### D-2: fixture constructor identity is a simple-name lookup with no implicit-constructor or initializer semantics
- **Where:** `linux-only-gate-witness.cs:496-525` (`IsNewFixture`) and `:201-213` (`GateContext.Ctors`).
- **Failure:** X05, X06 and X16.
- **Why:** a struct's `new S()`, a class's implicit default constructor, any same-named nested or other-namespace type, and `: this(...)`/`: base(...)` initializers or field initializers all escape.

### D-3: type groups merge nested and generic-arity twins into the row class
- **Where:** `linux-only-gate-witness.cs:229-244` (group building) and `:302-314` (`TakeGroup`, keyed by namespace and simple name). Used by `Covered` :353-366.
- **Failure:** X07 and X08. A decoy's gated constructor or `[Before(Test)]` "covers" an ungated test in the real class.

### D-4: the lexer diverges from C# and the divergence is accepted
- **Where:**
  - `linux-only-gate-witness.cs:1353-1404` (`Scan`)
  - `:1382-1389`: an unterminated `/*` runs to EOF with no `Misparse`.
  - `:1266-1292` (`NoteDirective`): an unclosed `#if` at EOF is never refused, and inactive-region text is lexed as code.
  - `:1392-1399`: identifiers ignore `\uXXXX` escapes and `Cf` characters.
  - `:1401`: a stray `\` in code becomes a silent token.
- **Failure:** X10, X11, X12, X13 and X14.

### D-5: gate arguments are evaluated before the skip
- **Where:** `linux-only-gate-witness.cs:611-620` (`SimpleArgs`). Dotted identifiers are property reads that can run arbitrary code.
- **Failure:** X15. This is the round-2 D-6 preamble, reopened through an argument.

## Recommendation (simplification, not a round 4)

Replace the source-gate witness with a **structural marker checked by reflection over the compiled test assembly**:

1. Add one sealed TUnit skip attribute, for example `NativeLinuxOnlyAttribute : SkipAttribute`, whose `ShouldSkip` is `!OperatingSystem.IsLinux()`. Put it in one fixed file and pin it by hash.
   - It applies at class or method level and is evaluated before the class is constructed, so constructors, fields, arguments and preambles never run on Windows.
   - Migrate the 45 rows from in-body gates to the attribute.
2. Make the witness a TUnit test in the same assembly, beside `WindowsUnitPlatformAdmissionTests`/`TestClassificationMetadata`, which already reflect over built types.
   - For each `Linux-only by construction:` row, enumerate every non-abstract type whose simple name equals the row class (case-insensitive) and every inherited test method, with the matcher's case-insensitive, all-overload method match.
   - Require `typeof(NativeLinuxOnlyAttribute)` (exact type identity) on each method or its declaring class.
   - Refuse an empty match.
3. Reflection sees what the compiler bound. Aliases, shadowing, `#if`, unicode escapes, partials, generics, nested types, `[Conditional]`, async and iterators all stop mattering.
4. Optionally, generate the rc exclusion rows from the attribute, so the policy and the proof cannot drift.

If a lexical check must stay as a pre-build guard, make it advisory only. The reflection test is the gate.
