## Split rule (scripts/impacted-classes.ps1 New-FilterRows)

1. A land class is a class name containing `Land`, case-sensitive. This is the importer's own count (PlanTableImporter `Contains("Land")`).
2. When a project's class row would name more than four land classes, those classes leave the row. They go four at a time, in ordinal order, to `<id>-land-1`, `-land-2`, and so on.
3. The other classes stay in the project row. That row is omitted when no classes remain.
4. Under `-MergeSubset`, the fixed land classes fill the first land rows. A land class that the batch diff selects starts a new row, so it never shifts a fixed row's filter or its measured floor.
   - Example: the migration range ff7cceaf gives `-land-3` = AgentTaskLandApprovalPersistence, AgentTaskLandingPersistence, LandRequestWriteDiagnostic, PostLandMutationAdmission.
5. Non-merge mode applies the same rule with no fixed set. Rows with four or fewer land classes are unchanged, so every existing selector pin holds, including the WindowsTestsFilter with LandGraphLandRefreshTests.
