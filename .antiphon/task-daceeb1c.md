## What `-Execute` now does (scope note for the operator)

`scripts/restart-linux-server.ps1 -Execute` never stops, starts or restarts anything. It probes the running server once (`/health`, then `/api/version`). A healthy server at the expected SHA prints `already at expected SHA` and exits 0 with no lock and no docker call. Any other outcome exits 5, writes the lock and leaves the container exactly as found: a well-formed different SHA runs three read-only `docker inspect`/`docker image inspect` calls to label the refusal `mismatch` (tag id equals the running image) or `image-moved` (the tag now points at another image); `/health` not 200, `/api/version` not 200 and a malformed body exit 5 with no docker call at all. `docker stop`/`docker start` no longer appear in the script except in the printed recovery hint.

Against the card: CARD-1745 reads "stop, start, then require /health and GET /api/version equal to the deployed SHA. A mismatch is a non-zero exit and leaves the container stopped or rolled back to the previous image." The repair delivers the "require" half only. The stop/start half is delegated to the CARD-1742 compose deploy (`docker compose up -d` recreates the container on the new image), after which this gate is the verification step. The "left stopped or rolled back" clause is consciously not implemented: round 1 ruled "left stopped" a production-down blocker, a `docker stop; docker start` can never change the served SHA (same container, same image), and a rollback needs the compose spec this script does not own. On mismatch the behaviour is now the restart-apphost.ps1 exit-5 behaviour the card cites as its model: the server keeps serving, the lock records the refusal, exit 5. A rollback is a compose redeploy of the previous tag by the operator. The operator should know that the script's name and `-Execute` are now misnomers for a verify-only gate, and may want to amend the card text; the acceptance can be met by the pair (compose recreate, then this gate), so this is a scope note, not a blocker.
