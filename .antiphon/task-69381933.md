## Rule

`Resolve-NightlyStoppedSeedOrder` in `scripts/lib/nightly-stopped-run-seed.ps1` ranks by integer priority, then timestamp ticks, then canonical ordinal. `priorFailure` is unchanged and stays class-wide.

- Priority 0: a chunk whose node list contains a failed method (class plus method, parameterised suffix stripped at the first `(`), or a chunk with no node list whose class has a failed method. A missing, null, or empty `nodes` property is no node list.
- Priority 1: never-seen or unfinished. A missing timestamp sorts as `[long]::MinValue`, ahead of a known timestamp. Known timestamps run oldest first.
- Priority 2: other chunks of a class that has a placed failed method (the affected-lanes band). After unfinished, before passed.
- Priority 3: passed.

A failed method the new plan does not contain is ignored. A failed method that moved follows the chunk that now contains it.
