- **D-1.** Candidate rows have no Detail column, and there is no migration. V-13's `runner_mirror_owned_by_retention` is the Removed row's ReasonCode. RunnerId is set.
- **D-2.** `"Enabled": null` makes the binder throw InvalidOperationException before any validator runs. Binding now goes through `Configure` and records an internal `BindError`, which the range validator refuses. So an unbindable value fails closed (OptionsValidationException), never the shipped-on default. A `ConfigurationChangeTokenSource` keeps hot reload.
- **D-3.** The residue sweep passes AsNoTracking releases to TryRetireAsync, so its state changes never persisted. That made V-22 "residue-sweep-first" end Partial. For system releases only, TryRetireCoreAsync now reloads a tracked row (and returns clean when it is Complete). - **D-5.** A row that throws (`release_failed` / `retire_failed`) stamps the retry cursor like a refusal.

They are refused at filing, after the read-only pre-check, so the "no git" assertion is replaced by "no mutating git".
