## Advisories (cards; they do not hold the land)

- **B-1** With a configured cap that is not a whole number of MiB, `FormatOver` can still collide. With a 14.5 MiB cap, a 14.52 MiB file prints `14.5 MiB` against `14.5 MiB`, because the one-decimal fallback rounds to the same text. The default 14 MiB cap is not affected. A fix would be to fall back to exact bytes when the one-decimal text still equals the limit's text.
- **B-2** `1 GiB - 1` bytes prints `1024 MiB`. This is cosmetic.
- **B-3** `IsThreadNotFound` matches the substring anywhere in the error text (the whole response body or an exception message) and does not check `error_code == 400`. It is safe in practice, but a check of `error_code` and `description` would be tighter.
- **B-4** No witness covers an album where only some items are over the cap. The code is correct here because the over-cap check runs before the key is added. Witnesses for this and the A-8 items (downloaded-bytes branch, FIFO eviction) remain for Mutation.
- **B-5** Astral Cf characters (tag characters U+E0001 and U+E0020-E007F) are surrogate pairs, so `GetUnicodeCategory(char)` sees `Surrogate` and they pass through the name filter. They are invisible and cosmetic for an LLM reader, and they cannot forge a line or a bracket.
