- **Failure:** `admission = build.AdmissionExitCode != 0` is also true after admission. The build-deadline path (`RunScheduler.cs:~558-561`) sets `AdmissionExitCode = Timeout` and `TerminalReason = "build-deadline-exceeded"`. "slot-timeout" : "slot-refused"`, which gives `slot-refused`. `CheckpointApp.cs:893-896` then projects explicit `executed=0 passed=0 failed=0 skipped=0`.
