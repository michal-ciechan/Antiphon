## What changed

1. Blocked-task Reply wire (`AnswerAsync` Blocked arm): the queued body is `TaskMarker + caller text + DelegationReportFormatter.BlockedReplyContract(taskId)`. The contract says the reopened turn must end with the COMPLETE final report again (outcome, files, counts, next-stage block), that an acknowledgement or the bare token is not a report, and restates the exact task-specific done/blocked/failed lines. It applies to every Blocked Reply (sync-blocked and question-blocked). The Replied event's `InputBody` carries the same text, so a runner-bound pointer spill serves it unchanged.
2. Token-only retention (`SettleAsync`, `ClassifyReportAsync`): a valid closing line with an empty body on a task whose `Result` is non-empty is "the turn added nothing". `Result`, `ResultFilePath`, `NextStage`, `NextHandoff`, `DeliverablePath`, `DeliverableRef` keep their values. The settlement event and the caller warning read `Turn ended with only the closing report line (verdict: x) and no report body; the retained report (N characters) stands and was not replaced.`
3. Bare `done`: on a live session with no prior ask, the existing bounded nudge is issued with token-only wording (`ReportNudgedAt` set, task stays Working; the parent waiting note says the earlier report is retained). After that ask was delivered and the child again ends with only the token, or when the session is dead, the task Blocks with the retained report intact. Bare `blocked`/`failed` keep their verdict's status (retained fields still kept). No English is parsed; no earlier verdict is copied across attempts; the reply watermark and `PreReply` selection are untouched.
4. The CARD-0248 post-nudge gates moved verbatim into `NudgeStillOutstandingAsync`, shared by the unmarked arm and the new arm. The strict last-line token parser is unchanged.
