## Decision for review: what the predicate means now

The old predicate was "(IsTestProject or Exe) and the project sits anywhere under `<repo>/tests/`". The new one is "the project directory's parent is `<repo>/tests`". All 23 tracked tests/ csproj files sit directly under tests/ (depth 3), and all 23 are test hosts or Exe, so the compiled set is the same today. Two cases would differ in future: a non-Exe library project added directly under tests/ would get the installer, and a project nested deeper (tests/a/b/X.csproj) would not. This is the only shape the evaluator accepts without new reserved names or policy changes.
