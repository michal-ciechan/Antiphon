## Change

`tests/Antiphon.Tests/Antiphon.Tests.csproj`, shared-output branch of `CopyStagedHelpers` only. The helper build's Properties gain `BuildProjectReferences=false;_GlobalPropertiesToRemoveFromProjectReferences=%3BOutDir`:

- `BuildProjectReferences=false` means the helper's references are only asked for their paths; they are not built again.
- The base build passed `OutDir=<helper folder>` to the helper, and that global property reached every ProjectReference. That is why `Antiphon.Server` compiled into `host-load-probe/` and `channel-outbound-probe/`. The fix removes `OutDir` from what the references inherit, so their paths resolve to the shared output they were already built into.
- The native, artifacts and relative-output branch (`_StagedHelperShared` false) is untouched.
- The fix uses an SDK-internal (underscore) property, which is a review point. It is the hook that `RemoveProperties` already reads for every ProjectReference MSBuild call in `Microsoft.Common.CurrentVersion.targets` (SDK 10.0.403).
