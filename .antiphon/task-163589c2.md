## Judgements

1. Every server call carries the header. All 10 Invoke-RestMethod/Invoke-WebRequest calls in
   the four scripts pass `$headers`. delegate.ps1 515, 636/638 (Invoke-Antiphon, plus the
   copy made for -ExtraHeaders, which copies `$headers` first), 967 and 1010. card.ps1
   256/259 (Invoke-Antiphon) and 738. status-snapshot.ps1 37. checkpoint-task.ps1 39. None of
   the four uses curl, WebClient or HttpClient. The dot-source and the Add line run at
   script top level, after `$headers = @{}` and before the first function that makes a
   request. No server call comes before them. The label is a literal registered value, so
   the throw cannot happen at runtime. Nothing dot-sources the four scripts. The helper is
   ASCII-only and uses no syntax newer than PowerShell 5.1.
2. On the server, `X-Antiphon-Caller` is read in exactly one place:
   AgentTaskEndpoints.cs:273 `polls.Record(header, caller)`. That is an in-memory counter for
   `GET /api/agent-tasks/{id}`. It does not reject requests and does not affect
   authorization or any other route. A missing or unregistered label falls back to the
   server-derived label, as before. No route authorization depends on the label. The six
   helper labels match `AgentTaskGetPollMetrics.RegisteredLabels` byte for byte (board-watch,
   card.ps1, checkpoint-task.ps1, delegate.ps1, status-snapshot.ps1, useagenttask), and
   CP-1's refusal method asserts this. Each script sends its own name.
3. When the helper refuses a value, the error is a constant string and no header is set.
   The server's TryRegistered also never echoes. The refusal witness covers runner-drain.ps1,
   phone-home and a blank value. The witnesses use a loopback HttpListener stub, like
   TaskCeiling/CardRelationship. The red result at 470a9191 is the author's stated 5/5. I did
   not rerun it; the mutant above stands in for it.
4. The six callers left unchanged (runner-drain, runner-slots, deploy-server2,
   verify-phone-home-grok, c1609-manual, postgres-cutover-monitor) are an acceptable scope
   limit. Without the header they get the server-derived label, which is how they behaved
   before. Nothing in phone-home breaks. Advisory only.
5. The plan rows were rerun, and so was the mutant. The real scripts ran only against the
   test stub. Nothing called a production server.
