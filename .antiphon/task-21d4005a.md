## Defects (Code landing owner: 82fa7fd1)

**D-1 A4 host stats are not wired. The producer-to-recipient path is missing.**
- Where: `scripts/lib/qualification-host-stats.ps1:1-84`. No script dot-sources it (repo grep). `nightly-tests-impl.ps1` never calls `New-QualificationHostStatsProvider` or `Invoke-QualificationHostSampler`.
- Failure: a Full run records zero host samples. There is no 30 s sampler and no owner-joined stop. There is no host-runtime receipt (executable, PSEdition/PSVersion, FrameworkDescription, assembly digest), and nothing loads the pinned SessionRunner probe. `& $Loader` in New-QualificationHostStatsProvider has no try/catch, so wiring it as written would let a loader fault throw into the runner instead of becoming `unavailable` telemetry. `Invoke-QualificationHostSampler` is a synchronous loop with no interval or deadline.
- Why: plan A4 says "called by nightly-tests-impl.ps1", and D-17/A-2 require load/read before credit. The author's report lists A4 as landed.
- Fix: wire a bounded, owner-joined sampler into the qualification under the TimingRoot with the host-runtime receipt. Wrap the load and read as unavailable-with-reason. Add a witness that drives the production call site. Native CP-2 `NativeHostSampleStops` stays owed.

**D-2 Stub assertion: `desktopLoaderCalled`/`net8LoaderCalled` cannot go red.**
