## Adversarial review of the final diff (no further defects)
- **Lock order:**
  - Hold (`TryHoldCeilingAsync`) and Continue/Extend (`AnswerCeilingAsync`) both take the settle gate, then the session queue gate, then the fenced save, where `RuntimeActionTaskFence` does `FOR UPDATE` on the session and task rows and rechecks status and token.
  - Cancel takes only the queue gate, and only for Working or held tasks. It releases the gate before the seat and workspace release (`AfterCancelCommitAsync`), which closes the db82c1e8 D-1.
  - No path takes queue then settle. No lock is held across a terminal release or a runner stop. CapacityLockOrderTests 17/17 and TerminalRunnerSeatReleaseTests 41/41 are green.
- **State machine:**
  - A double hold is prevented by `Active()` under the gates.
  - Continue racing Cancel: Continue reloads under the gate and its fenced save rechecks status and token, so it can never resurrect a Canceled task. Cancel observed as Dispatched, then a hold: the hold's fenced save fails on the status/token change.
  - Retry calls `CeilingHoldFacts.Reset`, and every claim path calls `Resolve`. `RequireImmutablePipelineEvidence` acknowledges an open episode on any terminal or Blocked save.
  - A held task stays Working and counted for its whole unanswered lifetime, including if it goes idle. This is the design in plan D-1.
- **Authority:**
  - Above 720 only `OperatorExtend` re-arms, and the endpoint calls `OperatorCredential.Require` before it builds the internal `CeilingOperatorAuthorization`.
  - `Rearm` refuses ordinary Continue/Extend once elapsed is at least 720 or the bound is already above 720.
  - The new reply fields cannot carry a caller-supplied authority.
- **Forwarder:** it only inserts notices. It never changes Status, Result, NextStage or the handoff. The FailureDelegate input waits for idle (`SupervisionInputCurrentAsync`). Cancelled typing is covered by `CanceledTypingBlocksTheComposerAsync`.
- **Upgrade:**
  - The migrations are additive and nullable; `CeilingOperatorExtended` is NOT NULL with default false. Old rows read as not held, and `Bound` falls back to the role ceiling.
  - Master's newest migration is 20261028170715, so the in-place edited 20261030214946 applies next from the master chain on any database that has not seen it.
  - The drift test (CardRelationshipSchemaTests, `HasPendingModelChanges`) is green in CP-205.
  - Every isolated test schema applies the whole chain.
  - Caveat (advisory): any environment that applied an earlier draft of 20261030214946 would skip it. None is known; the migration is unlanded.
