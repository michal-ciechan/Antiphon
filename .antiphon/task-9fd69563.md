## Advisories (cards, not land holds)

- A-1 (NETSDK1047/MSB3073 in Code's build 08): this race existed before this change. The diff does not
  touch PtyHost. After CARD-1664 (`359bd5d48`), `Antiphon.PtyHost.Tests` and `Antiphon.SessionRunner.Tests`
  each `Exec` a child `dotnet build` of PtyHost for linux-x64 into the shared `src/Antiphon.PtyHost/obj`.
  The likely mechanism, which I reasoned but did not reproduce: a second solution build in the same
  checkout re-runs the RID-less restore and rewrites `project.assets.json` under that child, so the
  child fails NETSDK1047 and the Exec fails MSB3073. My five overlapping builds did not hit it.
  Each qualification run start does one `dotnet build` in its own checkout, so this race should not kill
  a run start. It shows up when two builds overlap in one worktree, as in the review loops.
  Proposal, not implemented here: give the child copy step its own `MSBuildProjectExtensionsPath`/obj, or
  restore once for both RID shapes. That would also remove the need for the CS2012 retry proposed in
  the why-missed note.
- A-2: `EvaluationBudgetRefusesSlowDotnet` is red on master (check 4). The `bc96c71be` wrapper starts
  `dotnet` from PATH, and the test's shim answers `refused`, so evaluation never runs. It needs a Debug
  task or card if none exists.
