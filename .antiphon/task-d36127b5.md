## Behaviour

- `watch-qual.ps1`:
  - New optional `-TimingRoot`. When it is set, each poll (including `-Once`) prints exactly one line from `qualification-eta.ps1`. If the ETA script throws or returns more than one line, the poll prints `ETA-ERROR <message>` instead.
  - When `-TimingRoot` is omitted, stdout is unchanged. The script stays ASCII-only.
  - `rc-qualification-status.ps1`, its library and the heartbeat writer are not edited.
- `docs/release-gates.md`: the plan's sentence follows the `lastActivityAt` refusal directly.
- `rc-ledger.ps1`:
  - Accepts `antiphon-rc-ledger-v1` and `-v2`; v3 fails with `format`.
  - The scanner treats chunk `hostId` and `os` as optional string-or-null. `Test-RcLedgerDocument` refuses either field on v1 (`unknown-property:<name>`), so `Write-RcLedger` throws before any byte is written.
  - On v2, `os` is null, `windows` or `linux`.
  - The JSON writer emits the document's format. It writes `hostId` and `os` only on v2, as null when unset.
- `Set-RcLedgerDurations`:
  - Chunk duration is the sidecar `runWallSeconds`, matched on suite plus chunk.
  - Identity duration is the sum of TRX `UnitTestResult/@duration` for the identity's `className/method`, so `[Arguments]` cases add up.
  - The same identity in two TRX files is `duration-ambiguous`. A duplicate sidecar is `duration-duplicate`.
  - Anything unmatched keeps its value. Neither format nor host changes.
- `Set-RcLedgerHost`: throws `ledger-schema` unless the document is v2. It sets only the caller's `-HostId` and `-Os` (`windows` or `linux`) and never reads the machine name.
- `rc-ledger-stamp-duration.ps1 -LedgerPath -OutputPath [-TimingPath] [-TrxPath] [-IncludeHost -HostId -Os]`:
  - Refuses an existing output path (`ledger-exists`).
  - Refuses `-HostId` or `-Os` without `-IncludeHost`.
  - Writes v1 unless `-IncludeHost` is passed.
  - It has no nightly caller.
