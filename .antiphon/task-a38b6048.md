## Advisories (card them; they do not hold the land)

- **A-1. The production skip wiring and the status path have no witness.**
  - Mutant M4 survives. No test builds the dispatcher with a `RunnerRepositoryActivity`, and only C1817 references the type.
  - No test covers the path from the heartbeat through `PhoneHomeLiveConnection.cs:520` and `PhoneHomeRunnerDirectory.ObserveRepositoryMaintenance` to `GET /api/session-runners/{id}/status`.
  - The runner route `GET /repository-maintenance` (Program.cs:241) is also untested. Only DTO serialization is pinned.
  - Fix: add a dispatcher/DI witness and a server heartbeat-to-status witness.
- **A-2. The activity counter sees only the dispatcher's own `RunnerWorkspaceService`.**
  - Not counted: the retention workspace (Program.cs:91), the park service workspace (SessionRunnerRuntime.cs:218, which pushes), and agents' own git in the worktrees, which share the object store.
  - The docs promise a skip "while a task git call is in flight". That is narrower in practice.
  - Safety is still git's lock plus the prune expiry. Fix the doc or share the activity.
- **A-3. One error stops the whole gc owner until the runner restarts.**
  - `RunnerRepositoryMaintenanceService` catches `Exception` outside the timer loop (lines 27/32). Any non-cancel exception from `RunAsync` ends the owner with one warning.
  - One such exception: `CountLoose` calls `Directory.EnumerateDirectories(objects)` without a guard (RunnerRepositoryMaintenance.cs:175) and throws when the objects directory is unreadable.
  - Per-repository isolation is therefore incomplete: one bad repository also aborts the rest of that pass.
- **A-4. A kill can leave a stale lock.**
  - The budget or shutdown kill is SIGKILL on the gc tree. If it lands inside `pack-refs`, it can leave `packed-refs.lock`, which blocks later ref deletions until it is removed by hand.
  - The window is narrow, and there is no stale-lock note or handling.
- **A-5. A symlinked `.git` is still followed.** `IsRepository` uses `Directory.Exists(<child>/.git)` (line 305), which follows a symlinked `.git`. The reparse-point check covers only the child directory itself.
