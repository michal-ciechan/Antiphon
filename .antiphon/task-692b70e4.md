## D-1 The Merge-role refusal message has no cap; a long conflict list strands the land request

- **Where:** `server/Application/Services/AgentTaskLandingProtocol.cs` `MergeRoleDetail` (`string.Join(", ", files)`, new at :969-981, join at :980), reached from the new branch at :283-288. The text flows unclipped through `AgentTaskLandService.RefuseAsync` -> `PersistRefusalAsync`/`CompleteTerminalLockedAsync` into `AgentTaskEvents.Detail`, which is `varchar(4000)` (AppDbContext.cs:2506). It is written twice: once in the LandRefused terminal event (`land refused: merge_branch_needs_merge_role; <detail>`) and once in the Warning event (`Landing not confirmed; ... <detail>`). `Event()` (:2051) does not clip.
- **Failure:** a merge-commit branch whose first conflicting replayed commit touches 80 files of about 72 characters each. `land.RunAsync` throws `DbUpdateException 22001`. In the database the request stays `State=Running, IsPending=true, TerminalEventId=null`, and the operation stays `Phase=RebaseStarted` with `LastReason` null. No terminal event is written and no resolver is spawned. The land worktree and the source are not mid-rebase (the abort ran first). This is the stuck, unreported land state the card set out to remove. The message adds about 450 characters of prose, two 40-hex SHAs and the source ref to the file list, so it overflows at roughly 3.4k characters of file names. The old path overflowed only at about 4k. For a list between those sizes the fix turns a working resolver hand-off into a stranded request.
- **Why:** the brief requires "no unbounded file list (cap it)". The incident class (CARD-1545-size branches, plan-doc add/add) is exactly where long conflict lists occur.
- **Fix:** cap the files in `MergeRoleDetail`, for example the first 20 names and then `... and N more`. Keep the whole detail well under 4000 characters, since the Warning event carries it with a prefix. Add a witness: a merge branch with many long conflicting names reaches a LandRefused terminal and a Completed request. The inherited overflow of the plain `rebase_conflict` path (A-2) can be capped in the same slice, at `AgentTaskLandService.cs:766` (Conflicted event) and the Record call, or filed separately.
