## What the change does

One `MSBuild` call changed in `tests/Antiphon.Tests/Antiphon.Tests.csproj`. It is inside `Condition="'$(_StagedHelperShared)' == 'true'"`, so only the shared-output (checkpoint) layout is affected. That call now adds `BuildProjectReferences=false;_GlobalPropertiesToRemoveFromProjectReferences=%3BOutDir`. The native, artifacts and relative-output branch is byte-identical to base.

All 15 `StagedHelper` projects are direct `ProjectReference`s of Antiphon.Tests. Because of that, each helper and all of its references are built into the shared output before `CopyStagedHelpers` (AfterTargets=Build) runs. Skipping the reference build is therefore safe.

SDK 10.0.403 assigns `_GlobalPropertiesToRemoveFromProjectReferences` in only one place: when `PassOutputPathToReferencedProjects=false`, it appends `;OutputPath`. A global value would mask that append, but no project in the repo sets that property.
