# Debug 525e0201: read-only report-budget seed template

Test-side repair. Product report-store budgets and cancellation behavior are unchanged.

## Root cause and history

`ReportBudgetWorkspace.TemplateAsync` resets `<checkout>/.antiphon/test-output/card-1605/template` with raw recursive deletion before setting its process-local `_template`. Git init/add/commit creates that persistent seed repository. A failed reset leaves `_template` null and the same directory intact; every subsequent row/process repeats the failure. Case disposal already normalizes file attributes, so this is setup, not report-store teardown.

The denied basename is the suffix of tree object `831fc61e72b5c6b9570f91d6eabc272ad8f2899f`, at `.git/objects/83/1fc61e72b5c6b9570f91d6eabc272ad8f2899f`. `git cat-file -t` independently returned `tree` for the locally generated fixture. The exact seed is also catalogued in the CARD-1609 plan, D-17. The product AgentReportStore never recursively deletes a directory.

`git log -S 'Directory.Delete(template, true)'` identifies introduction in `d5b36458c6e288bb23d5164b8a2cbb7ef9d4b928` (2026-10-29). The fixture is byte-identical at previous rc cut `5a95ae7a5611eedb56c3bea023bb7a4b4fb6683a` and assigned base `10c3a8dd043326ac3abfefdb113b2fdd3e65a3c9`. The only budget-test change in that interval adds the NativeLinuxOnly marker. The store has no changes in that interval. Commits 1527c29fe/b37fc7bbd affect LandingGitFixture/RunnerSeatReleaseFixture and the separate GitTreeTemplate; they do not introduce this failure. No previous-run TRX was available locally and desktop access is prohibited. A clean first template build followed by a later process resetting the retained template explains a prior pass and later cluster; that timing is inference, not independently observed Windows evidence.

## Change and affected classes

Extract the existing reset into an internal method with an optional delete boundary, then call the existing shared `ReadOnlyDirectory.Delete` there. It clears read-only attributes before recursive deletion, avoids walking directory links, and propagates deletion failures. No retries or deadline changes: the supplied failure concerns persistent attributes, not a transient sharing violation. The existing five-second sharing retry is in LandingGitFixture disposal and remains independent.

Affected consumers: `AgentReportStoreBudgetTests`, `AgentReportStoreLoadTests`, and witness class `ReportBudgetWorkspacePortabilityTests`. No globally used cleanup implementation changed, so the many LandingGitFixture consumers are outside this delta.
