## Fixes

### D-1: walked helpers

- **Invariant.** A walked helper is resolved by its declaring type and its arity, never by name alone.
- **Bare and `this.` calls.** These resolve to methods of the caller's own type, or to a local function whose declaring block encloses the call.
- **Receiver calls.** `receiver.Name(...)` resolves only when the receiver's innermost visible declaration has a type declared in the walked roots. The declaration can be a local, a field, a parameter, or `var x = new T(...)`.
- **Arity.** `Takes(count)` honours default and `params` parameters.
- **Returns (A-3).** `ReturnsTainted` uses the same resolution, through a per-callee `()Type.Name` key.

### D-2: lambda parameters

- **Invariant.** A lambda gets tainted parameters when the call's receiver, or another argument, carries taint.
- **One reviewed exception.** The `write` callback of `ClaudeBlockingPromptDetector.ClearStartupTrustPromptAsync` (argument 1) is exempt. Its source, `ClaudeBlockingPrompt.cs`, writes only `ClaudeTrustDialogKeys` constants (lines 336/403/432/453). Without the exemption the startup canary is a false positive on `runner.WriteAsync(data)`. The reason is a comment on `IsKeystrokeCallback`.
- **Same-class extensions:**
  - A method group passed as the delegate argument of a listed delegate-taking leaf counts as Escape when it is handed taint, unless it resolves to a walked helper.
  - Query `from`, `join`, `let` and `into` range variables are tainted.

### D-3: stores

- **Invariant.** An element or member store is local only through a local that created its object in place (object, array or collection creation). The buffer-mutator exemption uses the same scoped declaration.
- **Same-class extension.** A `ref` or `out` argument of a call that carries taint counts, unless its target is a local or a discard. That required treating an undeclared `_` as local, because the diagnostics file uses `TryReadComposer(..., out _)`.
