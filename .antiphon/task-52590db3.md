## Advisories

- **A-1:** the native fixture runs `chmod` on the **shared** runner dind's `/var/lib/docker`. That daemon is this runner container's own, and every task on the runner uses it. Two concurrent CP-10 runs race: one run's restore breaks the other, and the last restore can leave `711` behind. The D-1 fix removes the `chmod`.
- **A-2:** `c1609_custody` loops forever on a relative path, because `dirname .` returns `.`. The inputs are constant absolute paths today. Add `[[ $path == /* ]] || return 1`.
- **A-3:** the CP-3 close budget of 150 s rests on one idle sample (69 s). The loaded close is censored at 120 s. Collect samples against the 2x p95 rule.
- **A-4:** the bridge `-cmatch` should anchor with `\z`.
- **A-5:** the preview treats a missing `c1008-volume-metadata.sh` as clean (`declare -F` false, so `meta=0`, so Ready), while apply refuses. Refuse the preview too.
