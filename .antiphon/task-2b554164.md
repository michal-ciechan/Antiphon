## R2-D-1 (blocker, regression): the non-merge selector output silently drops the land classes from its only filter line

- **Where:**
  - scripts/impacted-classes.ps1, line 944: `$rows = New-FilterRows $whole $methodsByClass '' $null`. The split now applies outside `-MergeSubset` too.
  - Lines 946 and 960: `Get-TopFilter`, and text mode printing only `treenodeFilter=<top>`. Non-merge text mode prints no `filter=` lines.
- **Failure:** this is the path the Code and Review bundles use ("impacted-classes rows whose globs match git diff base..HEAD"):

  ```
  pwsh -NoProfile -File scripts/impacted-classes.ps1 -Path server/Application/Services/AgentTaskLandNotificationService.cs
  ```

  - At 6393aed05 it prints `treenodeFilter=` with all 9 land-notification classes.
  - At the tip it prints `treenodeFilter=/*/*/(ReceiptScanDestinationIntegrationTests*)/*`. All 8 AgentTaskLand* classes disappear from the line. The `-Json` top-level `treenodeFilter` is the same partial filter. Only the `filters` array still carries the two land rows.
  - A Code or Review stage that takes the printed filter runs 1 of the 9 classes. That is the "selector row existed, no stage ran it" miss CARD-1801 exists to close, and it hits the land-notification row this card added.
- **Why:** the D-1 fix was about the importable Merge rows. Before this diff, the non-merge output always carried the whole Antiphon.Tests class selection in `treenodeFilter`. Now it loses classes with no signal. testing-and-build.md still describes `filters` as "one `treenodeFilter` per project". No test pins the non-merge `treenodeFilter` or text output for a selection of more than 4 land classes, so CP-1 stays green.
- **Fix:** either one works.
  - Apply the split only under `-MergeSubset`, and keep the unsplit project row in non-merge mode. The importer warning is advisory there.
  - Or make non-merge text mode print one `filter=` line per row, and document that `treenodeFilter` is no longer the whole selection.

  Either way, add a witness in ImpactedClassesSelectorTests: non-merge `-Path AgentTaskLandNotificationService.cs` output must name all 9 classes in what a stage runs. That witness is red at 34b759294.
