## What changed

D-1. The preview helper had `--network none`, so `git ls-remote origin` failed closed on a real volume. The preview now omits `--network`, matching apply.

D-2. Timeout and abort could leave a running helper, and a pre-existing name could be removed. The helper is `--init`, named and labeled for this run, and removed by its own id. A second delivery of TERM used to clear the owned id before `docker rm`; the handler now ignores further INT/TERM/HUP until release finishes. The watchdog sleep closes inherited pipes so an orphaned `sleep` cannot hold the caller's output open for the rest of the budget. The docker client does not close those descriptors.

Fixture. The simulated helper had no `/dev/fd`. The audit's process substitution then failed with `environment: line 745: /dev/fd/63: No such file or directory`, and an unpublished tip was counted as 0. A real image has `/dev/fd`; the stub now links `/dev/fd` to `/proc/self/fd`. With that link the same unpublished fixture reports `tips=1` and no stderr. A helper that exits without an `audit check=` line records `audit check=preview-helper` and its exit status. Inside `RollingVolumeRecycleScriptTests` the dry-run receipt had failed once at 10 s with `RecycleGitAuditUnknown audit check=unclassified` (31 passed, 1 failed) and passed when run alone. After this fixture fix the class passed 32/32.
