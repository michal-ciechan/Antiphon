## Deviations from the design (for Review)

1. **Post-connect socket-file re-check (added).** .NET's Linux `Connect(timeout)` spins on an absent socket inside its budget, so a socket that appears during that wait would never pass the pre-connect check. When the pre-check said Absent, `ConnectAsync` therefore re-checks the file after connect and before the hello.
   - Witness: `Socket_appearing_during_the_connect_wait_is_checked_before_hello` (CP-4; `Connections == 1` confirms the wait-then-refuse path).
   - Proposed PC (not in the design): delete the re-check; expect that method red at `ShouldBe(0)`.
2. **Manifest path in V-9 and V-9b.** These tests use `<root>/p/host`, not `<root>/p/<N>`. The world's pipe-name delegates take `(root, sessionId)`.
3. **Red-list delta at the shim.** The four Windows-platform V-18a cases were also red, because the shim returned this host's `PipeNameFor`. The red commit message records the full red list: 45 executed, 34 red.
4. **`EnsureSafe` order.** It checks the 107-byte bound before creating the directory, so an overlong path creates nothing. The design lists the bound as the last step. PC-38 and PC-70 are unaffected.
5. **Fixture race fix (`d4f311163`).** An Enforce refusal writes nothing, so the runner could connect and close before the fake host observed the accept. `PeerClosedAsync` then waited on the source that the accept had just replaced (Run L `20261103-023613-c682`, CP-4 `Forged_legacy_peer_is_refused` 17/18). The accept now reuses a pending source. No assertion or timeout changed.
6. **Logging.**
   - Refusal and observe lines are logged by the runtime, not the client. Per Q-2, the launch refusal is logged in `RunnerSession.StartAsync` and the adoption refusal in `AdoptCoreAsync`.
   - An unsafe launch directory additionally logs `pty_host_socket_dir_unsafe: launch refused for session <id>`.
   - The sweep diagnostic logs `<code>: adoption sweep socket directory check`.
7. **Custody adoption refusal.** The peer arm's `when (manifest.VerificationBinding is null)` sends a custody refusal to the existing generic arm, which never kills a bound host (I-S2-c).
