## What landed

Migration `20261006154102_AddBlockedTaskParkLegacyReclaim` adds `AgentTaskParks.LegacyDiscovery` (boolean, not null, default false) and an empty `BlockedTaskParkReclaimCursors` table. The cursor id is client-assigned. `Up()` does not update tasks, sessions, or workspaces.

`ReclaimLegacyAsync` runs only when parking is enabled, `ReclaimExisting` is true, the park service is present, and no ambient transaction is open. Page size and pass budget must be positive. The dispatcher calls it from `ReleaseUnownedPoolDelegatesAsync` after scheduled discovery and discards the visit count. `RunnerSlotReconcileJob` calls it with page 32 and budget 3 and adds the visit count to its return.

`LegacyDiscovery` is set only when the sweep inserts the episode. The fast path leaves it false. An existing episode is not flipped. The fresh window applies only to legacy episodes: `FirstObservedAt` must be present, `StableFor` must be at least 120 seconds, and that observation plus its stable duration must reach `park.CreatedAt` plus 120 seconds. An ancient `CompletedAt` does not open the window.

A missing report binding holds `park_binding_missing`. A shared live worktree holds `park_ownership_ambiguous`. Dirty, Working, and Unknown observations send no park release. The cursor commits after each visit, including a caught failure, and survives a process restart. Reply, cancellation, a newer block, an attempt change, a source change, a generation change, or a new claim at the list, reserve, or send barrier prevents the old park-version-2 release. Cancellation uses its own path and leaves the worktree in place. One reclaimed task cold-resumes from its pushed tip with the same agent.

`ReclaimExisting` stays default false. The S9 assertion is labeled "legacy discovery requires ReclaimExisting". G-188 belongs to S10.
