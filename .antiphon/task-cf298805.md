  the fetched published tip; task refs and HEAD reflog removed; free invariant with one retry.

  record (exact path, class, reason, error <= 4 KiB, branch, head, bytes, lock result), attention entries; the slot
  re-homes to `ws-NN-dK` (same id, lease generation continues); two failed replacements -> slot Failed

  id), weekly schedule (Sunday 02:00 UTC, Off|Daily|Weekly, missed boundary once at start).
- Quarantine release dispositions Pushed / AcceptLoss (diff, untracked list and patch retained first) / Removed.
- Crash recovery for transitional states and unconfirmed leases.
- `RunnerWorkspaceService`: slot branch of `MirrorAsync` (`Slot: true`), `RemoveAsync` refuses `slot_managed` for any

   untracked tree, because V-4/V-6b quarantine any dirty tree before a lease. Consequence: PC-1 (`--force` -> no
   force) has no legitimate state that reaches it; Mutation should pair it with PC-17.
3. V-2 plants ignored classes and an EMPTY cherry-pick (CHERRY_PICK_HEAD on a clean tree) for the same reason; the
   "untracked file" is an ignored `run.log`; no stash case.
4. V-7a uses a bounded 300 ms window inside the "picked" cut (green is deterministic; red under the lockless mutant
   is probabilistic).
5. V-10b is witnessed at the shared primitive `RemoveMirrorAsync` with cases slot-managed-refusal and
   slot-bound-no-request (not one case per consumer); V-12 is one method with 2 cases; V-37a covers the lease
   payload (the -ColdWorkspace -> column mapping is code-reviewed, not witnessed); V-41 is a slow recipient at the
   server's in-flight registry, not a held runner MutationLock (PC-74 not targeted by this shape).
6. Ownership ambiguity also requires the same runner id (slot ids are per runner).
7. Cold-reset route body is `{slots, all, reason, requester}` (not `slots: [...] | "all"`); the server audit is a
   structured log line, not a DB row (the runner ledger journals requester and reason).
8. Pool maintenance runs at start and on slot operations at most every 15 min; no dedicated runner timer.
9. `GET /sessions/workspace-slots` inventory and a quarantine-release server route/script verb are not built (S4).
10. Checkpoint table amended in a separate file (CP-4 floor 22, CP-18..CP-20) to avoid an add/add conflict with the
    TestDesign branch's copy of the design.
