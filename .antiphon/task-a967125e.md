## Advisories (not defects)
- **A-1 Redaction is not idempotent, and the real Windows path redacts twice.** `ModernConPtyConnection.cs:248` redacts, then PtyHost `launchFailed` → `PtyHostClient.cs:94` → `SessionReadLaunchRoutes.cs:60` redacts again. Input `x --append-system-prompt <3000 Q> --session-id k`: one pass gives `<redacted 3000 chars>`, two passes give `--append-system-prompt <redacted 9 chars> 3000 chars> --session-id k`. Nothing leaks, but the count is wrong on exactly the path this change exists to diagnose. Fix: treat an existing `<redacted N chars>` marker after a prompt flag as already redacted. Add a test that redacts twice.
- **A-2 Shape-based, not a secret scrubber.** The whole message is tokenised, but only the three flags and arguments over 200 chars are redacted. That is fine under the env-only credential policy. If any launch ever passes a token in argv, add that flag. Optionally add token-pattern scrubbing (`sk-`, `ghp_`, `xoxb-`, `AKIA`, `Bearer`, URL userinfo, `Password=`).
- **A-3 The 200-char rule over-redacts diagnostics.** A 258-char Windows path in `Could not find a part of the path '…'` becomes `<redacted 258 chars>`. An unbalanced `"` pulls the rest of the message into one token. Consider exempting rooted path tokens, or raising the limit for tokens that are not prompt arguments.
- **A-4 Last-error ordering.** At `ModernConPtyConnection.cs:248-250`, `Redact` and `Trace.WriteLine` now run before `LastError()` reads `Marshal.GetLastWin32Error()`. Today's default trace listener makes no SetLastError P/Invoke, so the code is safe now but brittle. Capture `Marshal.GetLastWin32Error()` right after `CreateProcessW`.
- **A-5 BadHttpRequestException.** The catch-all now turns a Kestrel `BadHttpRequestException` (400/413, which Kestrel used to map by `StatusCode`) into a 500 `runner_unhandled_exception` on every runner route. The server maps 400 and 500 alike (`HttpRequestException`), so this has no current effect. Consider adding `and not BadHttpRequestException` to the filter.
- **A-6 Runner log message clipped.** `RedactedFailureLog` uses `ForProblemDetail`, so the runner log keeps the stack but only 512 chars of each message. Use `Redact` without `Bound` there.
- **A-7 NUL (pre-existing).** `ColumnText.Clip` does not apply `WithoutNul`. A runner detail that contains `\u0000` would still fail the insert with 22021. Consider `ColumnText.WithoutNul(ColumnText.Clip(...))`.
