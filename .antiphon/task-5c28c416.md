The method names are kept, so the WindowsUnitSkipRoster entries stay valid (all 4 are listed there).

- C1008_Dry_run_preview_binds_a_dry_run_cleanup_receipt:
  - After the bound preview, an apply with the gate off refuses with exit 2 and `DIAGNOSIS=apply-gate-off`.
    It has no create or stop, no removal and no journal.
  - The token apply then completes using `C1609_TOOLING image=<current>`.
- AssertApplyMatchesPreview (dirty and unpublished blocks): after a refused preview, the token apply refuses
  with exit 2 and `RecycleGitAuditUnknown reason=preview-required`. It has no create, run or stop, no
  removal and no completed outcome. Previously it expected a content-audit replay.
- C1594_Cross_sha_cleanup_image_binds_the_retired_temp:
  - Every receipt shape (bound empty, cross-SHA, foreign retiredAt/projectId/project, missing historical
    image, no record, preferred) previews in the current tooling, and no historical image reaches Docker.
  - A gate-off apply refuses; the token apply completes.
  - Dirty and unpublished work still refuse.
  - Missing current tooling still refuses apply with `reason=current-tooling-unavailable`.
- C1594_Older_retirement_receipt_is_ignored: the older, bound, partial and dry shapes each produce a Ready
  preview in the current tooling. A gate-off apply refuses with no create, run, stop or remove.
- C1594_Disagreeing_cross_sha_images_refuse: the preview is Ready from content and neither image is used. A
  gate-off apply refuses with no effects.
- Unused FlagValue helper removed.
