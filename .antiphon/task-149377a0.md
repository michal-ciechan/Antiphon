## Custody and injection probe (sentinel names only; throwaway test, not committed)

- **TOML/argv injection is closed.** These inputs are refused with 422 `provider_endpoint_base_url_characters`: `"`, `\`, LF, U+2028, U+007F and any whitespace. The URL that is emitted is the raw validated string, not `Uri.AbsoluteUri`, so `%22` and `%0A` stay literal percent-escapes. Lookalikes (U+201C, U+FF02) are accepted as literal characters and cannot close a TOML basic string, because only U+0022 can. `=`, `'` and `#` are harmless: `#` is refused as a fragment. Each projected value is one argv element.
- **Userinfo:** `user@`, `:pw@` and `user%40x:p@` are refused with `_userinfo`. `https://@host` (empty userinfo) is accepted and emitted as-is. That carries no credential.
- **Schemes:** `ftp` is refused with `_scheme`. `file:`, `javascript:`, `data:`, `urn:`, `https://` and port 99999 are refused with `_relative`. `//host` is refused with `_scheme`. An empty or whitespace-only URL is refused with `_required`. A `{{key:` URL is refused with `_placeholder`.
- **No echo:** no 422/409 message quotes the URL or the key name. The unsupported-kind message names only the kind. Invalid key names are refused by `ApiKeyNaming` without echo. A null endpoint throws `ArgumentNullException`.
- **Normalisation:** `/v1/` and `/v1//` become `/v1` with no double `/v1`. `/` becomes `+/v1`. `HTTPS://Proxy.Local/V1` is kept verbatim. IDN, punycode, `[::1]:8080` and loopback are accepted.

## Disclosures (not defects under the verdict policy)

Expect SourceLanding Mutation to report these as survivors.
2. **`Parse`, `Serialize`, `ParseMap` and `SerializeMap` have no witness in S1,** as the Code report says (S2's round-trip test is the planned witness). `Parse` returns an unvalidated record, so a hand-written row with userinfo or a query survives Parse. The record's compiler-generated `ToString()` prints the full BaseUrl. Today nothing calls it and `For()` re-validates. S2 and S3 must not log the record or return a parsed row unvalidated; the plan's log line is host-only.
3. `Projected.Empty` is a shared static whose `Env` is a mutable `Dictionary` behind `IReadOnlyDictionary`; a caller could cast it and mutate it. Port 0, zero-width and bidi characters in the path are accepted. Out-of-range ports report `_relative` rather than a port-specific code. All of these are cosmetic.
4. Deviations from the plan's letter, all accepted: `ProviderEndpointMode` lives in `server/Domain/Enums` (the plan put it in ProviderEndpoint.cs; Domain must not reference Application). The 422 codes are split per rule. The characters rule is extra.
