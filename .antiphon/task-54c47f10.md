### D-3: closed sink audit

Invariant: in canary methods and helpers, a tainted value that reaches any invocation, creation, throw, or non-local store counts unless it is on an explicit allow-list.

Fix in `tests/Shared/LiveClaude/LiveClaudeSinkAudit.cs`: a new `Escape` count.

The allow-list:
- LiveClaudeEvidence projections;
- named bool predicates;
- reviewed bool or text-free product screen readers (ClaudeScreen.IsSettled/IsWorking/ComposerIsLive/TryReadComposer/ComposerContentIsEmpty, ClaudeDialogObservation.Observe, ComposerDeliveryEvidence.*FragmentIsVisible*, PromptSubmissionMatch.IsCompleteIn);

- walked helpers.

Taint handling:
- One taint set covers the walked roots.
- Taint flows into helper parameters, `out`/`ref` arguments and helper returns (`()Name`).
- Taint does not flow through sanitizing calls.
