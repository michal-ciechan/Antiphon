## Advisories (not blocking; file cards)

- A-1 (high: the shadow feature records almost nothing in a real run, and there is no producer-to-recipient test).
  - Where: nightly-run-impl.ps1 admission/closure (root `<LogRoot>/rc-run-evidence`) and nightly-tests-impl.ps1 build/launch (root `<runDir>/rc-run-evidence`, because nightly-run passes the run dir as LogRoot).
  - Failure: Build and Launch call AssertCurrent, which needs `source.json` in their own root, so they always refuse `inputs-changed`. The outer root is shared across runs, so `source.json` is write-once: from the second run on, admission refuses and closure says `source-moved`. Only discovery and chunk revisions are ever recorded. V-12 join and changed-input evidence is never produced by the nightly path.
  - Why: the witnesses call the functions with explicit roots, and the wiring check is only `String.Contains`.
  - Fix: use one per-run evidence root (the run dir) for all phases, and add a test that drives the real nightly-tests path through seams with recording forced (`ANTIPHON_RC_RUN_EVIDENCE=record`) and asserts build, launch and revision records.
- A-2 (decision): recording is on by default. It writes `rc-run-evidence/` under the nightly LogRoot and each run dir, runs git rev-parse and status in the checkout at admission and closure, and takes `.writer.lock`. If the operator wanted default-off shadow mode, flip the default to opt-in.
- A-3: swallowed failures are silent. Invoke-RcRunEvidenceCore discards `$msg` and callers `[void]` the result, so nothing reaches the run log. Write one warning line per refusal reason per run.
- A-4: "InterruptedWriterLeavesNotRun" witnesses a test-only `-Interrupt` seam. A real torn write goes straight to `revision.json`, not `.partial`, so `pending` stays `none`. The existing directory then makes every later revision fail `write-once`. Recovery and not-run marking should follow the real writer: write a temp file and rename it, and treat an orphan directory as not-run.
- A-5: the chunk outcome is `ExitCode -eq 0` only. Exit 0 with OutputDrainTimedOut, a missing TRX or incomplete coverage is recorded `Passed`. Derive it from the published chunk observation before any consumer reads it.
- A-6 (performance): Launch seals every dll, deps.json and runtimeconfig.json on every chunk (Antiphon.Tests: 280 files, 166.5 MiB). It also runs two git processes, inside the chunk phase stopwatch, under the run's own writer lock. That cost is hidden today by A-1's fast refusal. Measure it against the performance standards, or seal once per suite and compare stamps, before fixing A-1.
- A-7 (cosmetic): the inserted build-evidence block in Invoke-AntiphonNightlyTests is indented at 4 spaces inside 12-space code.
