# CARD-2077 dispatcher directory identity

The dispatcher and shared-writer lease projection now use `WorkingDirectoryIdentity` for
stored path spelling. The warm-pool lookup, scope comparison and live lease retain Windows
`OrdinalIgnoreCase`, which already matched pairs such as `Σ` and `ς`. The janitor retains
its invariant-uppercase Windows grouping in both cap passes. POSIX paths keep case and
treat backslashes as ordinary characters.

Task admission resolves the server-side working directory to an absolute path and takes
the Git top-level through `Path.GetFullPath`. Runner mirror locations live in
`RemoteWorktreePath`. The lease and reuse inputs are checkout or working-directory paths,
and I found no caller that uses case-insensitive POSIX identity. The stall probe opens
a local path, so its per-tick cache keeps `Path.GetFullPath` and the native case comparer.

The Linux witness failed before the fix on both mixed-separator Windows pairs and on
the case-distinct POSIX pair. Run `20261126-024654-22b1` at
`8c8cd220d18f4d6b18a4b0d2fdd6c15696cf4fe7` executed three results with three assertion failures.
The checkpoint recorded clean source and verified build provenance. The build took 803 s
and the test row took 16 s.

`Windows_git_toplevel_round_trips_to_the_stored_unc_path` supplies Git's UNC stdout
through `GitWorkspaceService.GetRepoToplevelAsync` and checks the stored-path match.
The Windows-only case uses the runtime skip roster and the Linux exclusion policy.
Its native run is pending while the desktop qualification holds the build slot.

The policy diff adds one Linux exclusion for that method under CARD-2077. Run
`20261126-030446-2d77` at `f3b4813b94fbbe0a9cbcf4a77714a91ec0c7c6a8`
passed 31 path cases with one Windows skip. Its guard row passed 58 of 59 cases.
The failing policy witness identified the stale policy hash and legacy exclusion
digest. Both pins and the live-lane input digest now account for the new exclusion.
