# CARD-2032 StartRef SHA witnesses

`C1349_PendingLandSurvivesLimits` now checks both spellings against a real pending sibling land. A unique abbreviated SHA resolves to the base commit but keeps dispatch queued. The full uppercase SHA dispatches from that commit and preserves the warning naming the uncontained sibling.

Replacing the full SHA check with a lowercase-hex check of any length reverses both outcomes. The abbreviated case detects the missing length check, and the uppercase case detects the missing case normalization.
