# CARD-2034 Match the StartRef to the repository object format

Git resolves a 64-hex branch name to a mutable ref in a SHA-1 repository. At the pre-fix commit `5ed2a6a5da9adbbd9c59fda9eeba2763154b6753`, the real Git fixture resolved the branch to a 40-hex commit and the dispatcher incorrectly dispatched during a sibling land. The build-slot run executed 11 cases, with that one failure and no skips.

For a same-repository pending land and a full hex StartRef, sibling inspection now runs `git rev-parse --show-object-format` within its existing deadline and Git command budget. The exception requires 40 hex digits for SHA-1 or 64 for SHA-256. An unsuccessful or unrecognized format probe leaves the ordinary hold and containment rules in effect.
