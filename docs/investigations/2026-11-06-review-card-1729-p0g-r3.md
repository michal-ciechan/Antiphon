## Advisories (one line each)

- A-11 (new in this diff, synthetic only): `LocalScope` over-scopes expression variables to the enclosing block. The shapes are an out var in a non-block embedded statement (`if`/`else`/`foreach`/`lock` body), a catch-filter pattern, a query-clause pattern, a foreach-expression out var, and a foreach deconstruction in its own `in` expression. In each, a later `Svc.Run()` binds to the type but is skipped. The oracle shows none on the real tree. Fix: treat a non-block embedded statement as its own scope; use `CatchClause` for `CatchFilterClause`, the clause for query clauses, and the `ForEachStatement` for foreach expressions.
- A-12 (new, false rows, none on the real tree): `LocalScope` under-scopes in three cases. A switch-section local should get the whole switch block, a top-level-statement local should get every global statement (here it gets only its own `GlobalStatement`), and query range variables are not declarations.
- A-8 (round 2, pre-existing): `own`/`localTypes` treat a nested type in a *sibling* class as in scope. Both `class A { class Svc {} } class V { … Svc.Run(); }` and the type-position form are missed. The oracle shows none on the real tree.
- Pre-existing: a reference made only through `using static`/alias directives is invisible, because using directives are skipped. The oracle shows none on the real tree.
- A-10 (cost): the shared real-tree setup in CP-1 is `LAYERING files=1349 census=0.012s read=0.144s analysis=9.500s total=9.657s`. Probe processes measured 4.3-10.0 s, or 26.1 s with tracing on and concurrent load. The CP-1 host wall is 19.1 s, of which 18.4 s is startup, and the per-test durations are 0.6-49 ms.
