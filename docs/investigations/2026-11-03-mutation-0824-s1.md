# Mutation sweep: CARD-0824 S1 per-slot worktree pool

Task e87df8c7 (Mutation, waived). This was an ordinary-worktree sweep on master
`e56e4d1b6a727b3127b473307b860b7117980f09` (L). It covers CARD-0824 S1: the runner slot pool (`8395c4a43`), the
server half (`e06ef3073`), the review fixes (`20fac33a1`, `7ab9aa36c`) and the Linux-only gating (`f32aed42e`). It
ran on server2 (Linux) on 2026-11-03 from 20:38 to 22:15 UTC, inside the 120-minute budget.

**These results are NOT CARD-0478 evidence.** No SourceLanding was commissioned, and this sweep was waived to an
ordinary worktree. No product or test code was changed, and nothing was landed.

## Outcome

**103 mutants ran: 73 positive-control mutants (PC-1..PC-74 less two that do not apply, with PC-57 split in
two) and 30 extra safety mutants. 90 were killed and 13 survived.**

- **Positive controls.** 70 of 73 were killed.
  - Survivors: PC-06, PC-13 and PC-74.
  - PC-61 and PC-72 have no mutant. The Code checkpoint amendment dropped V-54 (S1 land cleanup never touches
    the runner slot) and deferred V-56 (base selection). No witness exists for either. The server never sees a
    slot's parked sha, so PC-72 cannot be written as a server mutant.
- **Extras.** 20 of 30 were killed, including the brief's three retention guards (X45, X46, X56, X57), and 10
  survived.
- **Dangerous.** **X37** is dangerous: idle retirement without its preflight runs `git worktree remove --force` on
  a dirty Free overflow slot, so data is deleted. X17, X11, X31 and X06 are safety gaps without a witness.

## Method

- **Gate.**
  - Every mutant was compiled in behind `M0824R.On(id)` (runner), `M0824C.On(id)` (Contracts) or `M0824S.On(id)`
    (server). Each one reads `M0824_MUTANT`.
  - The helpers were the untracked files `src/Antiphon.SessionRunner/M0824R.cs`,
    `src/Antiphon.SessionRunner.Contracts/M0824C.cs` and `server/M0824S.cs`. All three were deleted afterwards.
  - With the variable unset, the code is L. The server-lane runs used the runner gates through the Antiphon.Tests
    build, for PC-71 and PC-74.
- **Builds.** Each build had its own build-slot lease, with native default output, `-p:UseAppHost=false` and
  `TEMP=/tmp`:
  - gated `tests/Antiphon.SessionRunner.Tests`: 27 s
  - gated `tests/Antiphon.Tests`: 178 s
  - restore builds at L: 74 s and 272 s
- **Runs.** Every run was `dotnet run --no-build --project <P> -p:UseAppHost=false -- --treenode-filter <F>
  --report-trx`, one lease per run and one mutant per run. The only exception is the declared X56+X57 pair. At
  most four runs went in parallel, and the runner and server lanes never shared a run.
  - **Runner PCs** used class-scoped filters mapped from the design (for example PC-22 ->
    `C0824WorkspaceSlotCustodyTests`).
  - **Runner lane:** the seven C0824 runner classes plus `C1677RetentionEngineTests` (114 tests).
  - **Server lane A:** `/*/Antiphon.Tests.Application/(C0824WorkspaceSlotServerTests*)|(PhoneHomeRollingRunnerDrainTests*)|(C1656RecordReleaseHardeningTests*)/(C0824_*)|(C1649_*)|(C1656_*)|(C1670_*)|(C1673_*)`
    (34 tests, `--maximum-parallel-tests 4`). The drain methods live in partial class `PhoneHomeRollingRunnerTests`,
    so lane A did not run them.
  - **Lane D:** `PhoneHomeRollingRunnerTests*/(C0824_*)|(C1649_*)` (4 tests). X59 and X54 were rerun on lane D. X59
    is killed only there; its lane-A "survived" result is void.
  - **Lane R:** `C1677RetentionServerTests*` (55 tests).
- **Baselines** (gate compiled in and off): r00 114/114, s00/A 34/34, s00d/D 4/4, s00r/R 55/55.
- **Restored green at L** (rebuilt): r99 114/114, s99/A 34/34, s99d/D 4/4, s99r/R 55/55.
- **Load.** Build-slot waits were 0-354 s; the broker had 4 slots, shared. No red needed a lone rerun. Every
  killed mutant failed only tests that are green in its own lane's baseline.
