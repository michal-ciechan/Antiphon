## Item 4 on current master

Master commit 794aa6f1f, committed 09:25 after this task's base, ports the release selection to C# (unit 8 of the 2026-11-22 ps1-to-C# plan). It deletes `scripts/test-change-aware-release.ps1`, the five `ChangeAwareReleaseTests.C1590_*` tests and `ChangeAwareReleaseBudgetTests`, because the in-process fixtures dispose their own roots. So master no longer has the gone-root scan or the provider copy, and the C1590 timeouts cannot recur there. This branch first fixed the harness (bd72cff38, 5364ddf0f) and measured the fix above. It then restored the script to its base bytes, so landing keeps master's deletion. The measurements remain as the cause of the review-row timeouts on bases before 794aa6f1f. One lesson carries over to any remaining PowerShell harness: on Linux, `Get-ChildItem -Recurse` on a path that may be missing must use `-LiteralPath` behind a `Test-Path` guard, and `Copy-Item -Recurse` costs about 85 ms an entry.

## Why they were missed

1. **Socket roots.** CARD-1653 S2 (463af4232, 2026-11-03) sized its roots for `/tmp/`: the default socket path was 105 of 107 bytes. It guarded that sizing with an assertion where it should have provided headroom. CARD-1981 S2 (2026-11-18) moved every leased test host's TMPDIR to `/tmp/aslot-<8 hex>/`. Its witnesses covered the SDK temp confinement, not tests whose path budgets depend on `GetTempPath()`. A plain `dotnet run` still has TMPDIR unset, so local and author runs stayed green. Only checkpoint rows, the Full review lane, ran under the lease.
2. **Unlisted Windows skips.** C665/C721 (2026-09-25) and the confinement case (2026-10-17) predate the placement check. C1717_B3 (2026-11-05) predates it by 11 days. CARD-1958 made a Linux skip valid only when it is on the committed roster, but did not back-fill existing `Skip.Test` guards. `C1210_Roster_closure_matches_source_gates` scans only `NativeLinuxGate`/`C1008HostFixture` gates, so nothing static finds a `Skip.Test` behind `!OperatingSystem.IsWindows()`. The validator sees one only when a Linux Full row selects it. A census on 1b057c8c6 finds about 40 more `Skip.Test` calls behind `!OperatingSystem.IsWindows()` in `Antiphon.Tests` (41 grep hits, one inside a selector-test fixture string) with no roster row. Each will return `skip_identity_unlisted` the first time a Linux receipt selects it. A static census that pairs each such guard with a `WindowsOnly` row would close this gap.
3. **C1313 exact execution.** The test moved from `scripts/test-test-selection.ps1` to C# on 2026-11-22 (6c43a4778). Before that, S04 (407afd599, 2026-11-21) had put the Windows-only `NativeProcessOwner` into the core, and the Linux portable launcher had already been removed (4662c5298, 2026-10-27). The move kept the production host and added no platform guard. Its verification ran on Windows or did not select this method on Linux.
4. **C1590 gone root.** The `Get-ChildItem $root` line (5c273a3de, 2026-10-19) was harmless while every root existed. CARD-1691 (07b5856a7, 2026-11-03) added the gone-root cases, which made the missing-path walk real. Its cost grows with the results directory and with the per-entry provider cost on Linux. The fixture grew afterwards (the copies of all tracked `*.csproj` files and of the nightly core sources), so the cases moved from under the 300 s budget to straddling it: 2 of 6 alone runs on master still passed, at 285.6 s and 294.2 s. The harness's 300 s default hid the slowness until load pushed it over.
