## Method

- **Gate.**
  - The mutants were compiled in behind two untracked helpers, both deleted afterwards:
    - `server/M1679S.cs`: `M1679S.On(id)` reads `M1679_MUTANT`.
    - `src/Antiphon.Agents.Pty/M1675P.cs`: `M1675P.On(id)` reads `M1675_MUTANT`.
  - B16 in `Antiphon.SessionRunner` read `M1675_MUTANT` inline.
  - With the variables unset, the gated code is L.
- **Builds.** There was one gated build per test project, each under its own build-slot lease, with native default output, `-p:UseAppHost=false` and `TEMP=/tmp`:
  - `Antiphon.Agents.Pty.Tests`: 22 s
  - `Antiphon.SessionRunner.Tests`: 32 s
  - `Antiphon.Tests`: 153 s
  - After each build, the gate symbol was confirmed in the output DLL.
- **Runs.** Every run was `dotnet run --no-build --project <P> -p:UseAppHost=false -- --treenode-filter <F> --timeout 10m|20m`, under its own lease, one at a time. The Pty, runner and server lanes always ran separately. The load average was below 3.
  - C1679 lane: `/*/*/(CapacityAdmissionLifecycleTests*)|(AgentSessionRuntimeBoundedReadTests*)/C1679*` (11, about 25 s)
  - boot-wedge lane: `/*/*/(BootWedgeRelaunchParityTests*)|(SessionMessageQueueBootWedgeTests*)/*` (12, 53 s)
  - phone-home lane: `/*/*/(PhoneHomePendingInventoryTests*)|(MultiRunnerDirectoryTests*)|(MultiRunnerRecoveryTests*)|(AttentionServiceTests*)|(SessionMessageQueueDeliveredSpillRecoveryTests*)|(SessionRuntimeActionTemporaryBlockTests*)|(PhoneHomeStrandedQueueTests*)/*` (215, 92 s)
  - consumer lane: `/*/*/(AgentSessionServiceIntegrationTests*)|(AgentTaskPoolTests*)|(BlockedTaskParkReleaseTests*)|(AgentTaskCheckSweepTests*)/*` (111 with 1 skip, 190 s)
  - Pty lane: `/*/*/GrokNativeSessionStoreTests*/*` (23: 20 pass, 3 Windows-junction skips)
  - runner lane: `/*/*/HerdrGrokResumeGuardTests*/*` (9)
- **Isolation.** There was one mutant per run. The survivors of a narrow lane were rerun on a wider lane, as listed in the results.
- **Baselines** (gate compiled in and off): s00 11/11, w00 12/12, d00 215/215, l00 110/110 (+1 skip), p00 20/23 (+3 skips), r00 9/9.
- **Restored green at L.**
  - Sources were restored with `git checkout --` on the five tracked files, and the two gate files were deleted.
  - All three projects were rebuilt, and no gate symbol was left in the DLLs.
  - Results: s99 11/11, w99 12/12, p99 20/23 (+3 skips), r99 9/9.
  - Afterwards, the tracked source and the index were clean at L.
- **No load flakes were seen**, so no lone reruns were needed.
