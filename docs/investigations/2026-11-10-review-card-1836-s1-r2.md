The token scan runs before `ConvertFrom-Json`. Trailing commas, comments, single quotes, `NaN`, and leading zeros never reach the parser, so PowerShell's looser parser cannot keep a second outcome. Case folding uses ordinal ignore-case. Unicode normalization is not applied: a lookalike is an unknown name and is rejected, which is the closed direction.

The depth ceiling (`Frames.Count -gt 12`) was not the rejecting check. The schema has no recursive object, so a nested bomb dies as an unknown name or a type error before deep recursion. The scanner walks tokens in a loop. A 40-deep document did not overflow the stack.

A duplicate in `baselineSha` or `policyHash` is rejected even though the carry predicate does not read those fields. `Read-RcLedger` throws before `Get-RcIdentityCarryDecision`.
