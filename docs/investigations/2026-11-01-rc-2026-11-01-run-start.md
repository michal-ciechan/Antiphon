## Failure

`commission-console.log`: `running ...\nightly-tests.ps1`, then
`Exception calling "GetBytes" with "1" argument(s): "Value cannot be null. (Parameter 'chars')"`, then exit 1.

Root cause: `scripts/lib/release-selection.ps1` `Invoke-ReleaseSelectionHop` treats only
`NoSync`/`NoReport`/`WhatIf` as switches. The rc profile always builds a selection attempt, so the
tests hop always goes through this function. `-AcceptCrossCandidateSeed` therefore consumed `-SeedSourceCandidateId` as its value.
The candidate id then became a key with no value, and `UTF8.GetBytes($null)` threw. Reproduced at the same SHA
with a synthetic argument list, which throws inside the loop before any process starts. Fix: add `AcceptCrossCandidateSeed` to
that switch list. The receiver already splats `[bool]` values. A regression test needs to feed the rc hop with a seed.
No existing test covers the hop with a seed: `test-nightly-stopped-seed.ps1` uses Trigger manual, which has no selection attempt.
