The task-detail seat projection reported `release unconfirmed` because its fresh-inventory predicate did not succeed. The direct slot response confirms current occupancy. ## Release risk and rollout gate

Both normalized transcripts end at the failed footer and turn boundary. Both message reads returned zero rows and `working=false`, and both task details have `commitOnSettle=Never`, null deliverable and null sync debt. `git ls-remote origin` returned `d980e90c631e93941bb71debb9faf1829ca7c21c` for both `refs/heads/feat/card-task-7c3daf8a` and `refs/heads/feat/card-task-6d5b2869`, equal to both recorded worktree bases. The reports and remote refs show no expected work product. The old mirrors (`/work/worktrees/ws-03-d3` and `/work/worktrees/ws-02-d3` in the earlier capture) are on the old runner's private work volume. They were unavailable in this worktree, and SSH from here failed strict host-key verification. The live mirror dirty state and local-only refs remain unverified. The exact-seat release stops the process, drops runner session custody and records an audit. The runner retains the checkout and the server retains the session row. The default `redeploy-old` keeps the main work volume. [Release implementation](../../src/Antiphon.SessionRunner/SessionRunnerRuntime.cs#L1845) · [Server audit](../../server/Application/Services/RunnerSlotService.cs#L355) · [Volume policy](../docker-stack.md#L392)

Both late reports are already captured in the server's notice ledger. Their `LateFailedParent` deliveries remained `Pending` at the read (`458ad56a-a5b2-403e-90ae-d5013dd24029` for ladder and `066dee46-4b32-4b6a-b8c2-2f4605f2eb9a` for Astra). `redeploy-old` checks zero before replacing the worker container. The Compose recreate ends any process inside that container and keeps the default work and state volumes. It does not transfer a live standing process to another host. For a genuine standing seat, the documented CARD-1778 path records the existing agent and session, stops it in the operator window, prepares the sidecar directory, patches the agent, fresh-starts it there and verifies the new session. A still-configured, unsuspended AlwaysOn agent is eligible for its normal supervised restart once its runner is available. The Windows parent and the separate Linux `server-session-runner` sidecar are outside the worker container being replaced. CARD-1778 re-homing is inapplicable to both canaries.
