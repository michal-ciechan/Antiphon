## Method

- **Gate.**
  - Every mutant was compiled in behind `M1677R.On(id)` (runner) or `M1677S.On(id)` (server). Both read `M1677_MUTANT`, a comma-separated list.
  - The helpers were the untracked files `src/Antiphon.SessionRunner/M1677R.cs` and `server/M1677S.cs`. Both were deleted afterwards.
  - With the variable unset, the gated code is L.
  - The JSON mutants (J01-J10) needed no build: the settings test reads `server/appsettings.json` from the repo root. Each was one `sed` on one line, a run, then `git checkout -- server/appsettings.json`.
- **Builds.** Every build ran under its own build-slot lease, with native default output, `-p:UseAppHost=false` and `TEMP=/tmp`:
  - gated `tests/Antiphon.SessionRunner.Tests`: 43 s
  - gated `tests/Antiphon.Tests`: 174 s
  - gated runner rebuild that added R36: 17 s
  - restore builds at L: 197 s and 18 s
- **Runs.** Every run was `dotnet run --no-build --project <P> -p:UseAppHost=false -- --treenode-filter <F> --report-trx --timeout 20m`, under its own lease, one at a time and never concurrent. The runner and server lanes always ran separately.
  - runner lane: `/*/*/(C1677RetentionEngineTests*)|(C1677RetentionInventoryTests*)|(C1677RetentionDispatchTests*)|(C1677RetentionNativeProcessTests*)/*` (57 tests, 18-40 s)
  - server lane: `/*/*/(C1677RetentionServerTests*)|(C1677RetentionSettingsTests*)/*` (66 tests, about 50 s)
  - JSON lane: `/*/*/C1677RetentionSettingsTests*/*` (14 tests)
- **Isolation.** One mutant per run, so no pairing ambiguity. The only exceptions are the declared layer pairs.
- **Baselines** (gate compiled in and off):
  - r00 57/57
  - s00 66/66
  - b2-none 57/57 after the R36 rebuild
- **Restored green at L:** r99 57/57, s99 66/66.
- **Load.** The load average was about 17-22, and there were no load flakes.
  - **S10 lane.** The S10 lane run was red 40/66, all at the class `[Timeout(45_000)]`. That is cross-talk: every World shares the test database, so dropping the runner-id filter makes concurrent worlds send each other's tasks.
  - **S10 lone runs.** A lone `Terminal_statuses_at_the_age_floor_are_sent` run was green 3/3. A lone `Each_ineligible_task_alone_is_recorded_and_never_sent` run was red 1/23, at the intended case and assertion: `(other-runner)` line 213, 2 requests sent instead of only the control. S10 counts as killed at that assertion.
  - **R19 and R23 lone reruns.** Both were rerun alone and stayed red.
