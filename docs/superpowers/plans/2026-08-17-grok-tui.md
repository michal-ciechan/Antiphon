# Grok Build TUI as a first-class Antiphon runner

**Date:** 2026-08-17
**Status:** implementing

## Verdict

Antiphon does **not** support Grok as a TUI today.

`AgentKind` is `Raw | ClaudeCode | Codex | OpenCode`. Grok appears only as an
OpenCode *model identifier* (`llmgateway/grok-4-5` / `maven/grok-4.5`) behind
a wrapper. The installed runner is Grok Build TUI 1.0.4 at
`%USERPROFILE%\.grok\bin\grok.exe`.

## Target

Treat Grok the way Claude Code is treated as a terminal runner:

| Surface | Behaviour |
|---|---|
| `AgentKind.Grok = 4` | First-class kind; persisted numeric contract |
| Profile catalogue | `grok-4.6`, `grok-4.5`; `--model`; `grok models` discovery |
| Launch | `--always-approve --no-alt-screen`; `--session-id` / `--resume` / `--continue` |
| Standing instructions | `--rules` (Grok's append-system-prompt analog) |
| Resume | Same cwd + session id as Claude |
| Activity | Quiet-time (ACP `updates.jsonl` is **not** Claude JSONL; do not enable the Claude tailer) |
| Fake | `fakegrok.exe` models grok's CLI + the PTY submit contract Antiphon depends on |
| Tests | Factory, catalogue, launch, discovery, resume, FakeGrok contract, queue→PTY |

Out of scope until measured against real Grok: Claude JSONL tailing, remote-control
(`/remote-control`), trust-dialog auto-answer, compaction/interrupt working-idle
rules, headed canaries.

## CLI facts used

- `--model` / `-m`, `--session-id` / `-s` (new UUID only), `--resume` / `-r`, `--continue` / `-c`
- `--always-approve`, `--permission-mode`, `--no-alt-screen`
- `--rules` extra system prompt; `--cwd`
- `grok models` lists `grok-4.6` (default) and `grok-4.5` in prose, not one-id-per-line
- `grok --version` → `grok 1.0.4 (d846eb93d9) [stable]`
- Sessions: `~/.grok/sessions/<url-encoded-cwd>/<session-id>/` (`GROK_HOME` overrides)

## FakeGrok contract

Same PTY submit contract as FakeClaude (Antiphon's queue depends on it for every TUI):

- Banner `Fake Grok ready`, then quiet
- Lone CR/LF burst submits; text+CR in one write is a paste
- Mid-body `\r` fragments; `\n` is literal
- Composer echo; opt-in clip / swallow-enter / paste-placeholder
- Turn end: `Crunched for 1s` + idle OSC title, then quiet
- `--version`, `models` (real grok prose), `--session-id` / `--resume` / `--cwd` / `--echo-args`
- Session files under `GROK_HOME` when set
