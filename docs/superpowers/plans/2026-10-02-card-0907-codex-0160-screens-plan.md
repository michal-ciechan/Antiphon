## Design decisions

### D-1: one credential-free desktop turn, with honest provenance

Code captures the real **interactive** desktop 0.160.0 TUI in a new temporary `CODEX_HOME` and scratch Git workspace. Use the repository's `RealCliStubEnv.ForCodex` and loopback `FakeLlmApiServer` to spend at most **one TUI submission**, requesting exact model `gpt-6.1-sol` and `model_reasoning_effort=low`, with a short nonce-only prompt and response. This reconciles the sanctioned one-turn budget with the explicit prohibition on real-account material. The CLI's screens and rollout are real; the provider response is scripted. Record `provider=loopback-stub`, **not live-model qualification**. Confirm the stub received this nonce/model/effort; process exit or a banner is insufficient. If the installed CLI cannot complete this isolated path, report the capture gate pending; do not copy auth, use the persistent headed-test home, silently substitute another model or make another submission.

A scratch helper may reuse already-built test/support assemblies from the checkpoint build; any necessary one-time capture-helper build must be explicitly reported and build-slot leased. It is not an implicit license to run real CLI canary suites. Do not launch the currently deployed server2 Codex for capture. Snapshot/replay rows on Linux need no installed Codex.

Use a child-scoped allowlisted environment, explicit scratch home and file-based credential store, synthetic-only auth/key from the existing helper, apps/MCP integrations disabled, and only loopback provider traffic. Never enumerate or read a real Codex home or dump inherited environment. The helper already seeds synthetic bootstrap metadata and an unelevated Windows sandbox choice; remove/alter those **scratch-only** choices for a specific no-turn onboarding capture as needed. Do not use an actual ChatGPT login to obtain post-login screens.

Rejected: live subscription login/auth copying; `codex exec` as a substitute for interactive rollout shape; multiple turns to exhaust quota or force compaction; claiming a stub-backed capture proves real-service model availability. Real-service/model adoption belongs to the later operator canary and CARD-0903.

### D-2: fixture provenance and geometry are part of the evidence

Capture at **120 columns x 30 rows initially**, with modern ConPTY and the production launch flags. A separate no-turn 120x40 trust capture may corroborate the investigation; replaying a 40-row stream in a 30-row renderer is not a native 30-row capture. Preserve complete VT from session start through each named stable frame, including erase/cursor/synchronized-output sequences and byte offsets at frame boundaries. Replay sequential deltas on a persistent `TerminalScreen`, and independent full prefixes on a fresh screen. Exercise whole-buffer, one-character and irregular chunk boundaries, including inside CUP/CUF sequences.

Each new `.txt` fixture starts with a loader-owned `#` metadata envelope and a fixed `--- payload ---` separator. Required fields: CLI version, actual capture UTC date, cols/rows, OS/backend, `captured` / `captured-stub-response` / `synthesised-vendor` / `derived-regression`, source URL+revision/date where applicable, decoded payload hash, and every redaction. Loader removes the envelope **before** rendering/classification. Store raw VT as an explicitly documented escaped representation (`\u001b`, CR/LF, etc.) and decode once; do not call ANSI-stripped text raw. Assert independently recorded expected rendered rows; never generate the expected screen with the same renderer during the assertion.

Use `v0160-` names under the existing screen fixture directory. Keep older fixture bytes and their current loading behavior unchanged. Rollout remains valid JSONL, without comment lines: put version/date/geometry/provenance in `v0160-tui-turn.metadata.json` beside it. Retain session metadata and structural event ordering; redact account identifiers, local paths, IDs consistently and documentedly, removing irrelevant environment/encrypted payloads without inventing events. Read only the JSONL written inside this task's scratch home. Do not copy auth/config/model caches into fixtures. Delete a generated rollout only through the Codex CLI in that scratch home, never by manually deleting a rollout from a persistent home.

Rejected: reconstructing raw cursor moves from the investigation's prose and calling them captured; metadata painted onto the screen; unlabelled synthetic layouts; account-home transcripts; relying on filename version as proof of capture version.

### D-4: conditional minimal repairs, with existing behavior preserved

1. A rendered startup/trust/update/Working case that passes needs fixtures/tests only. On a failing vendor-grounded literal/layout, change just its Codex predicate; preserve current-frame authority, exact idle layout, one Enter/one Escape, original deadline and fresh settle. Unknown post-login dialogs never earn automatic Enter, Escape, or readiness just because an idle hint remains underneath.
2. Keep transcript completion primary and baseline-qualified. Compaction-only JSONL must emit no `TurnEnd`; a long quiet frame must not complete a turn that never showed Working. If vendor compaction removes Working while remaining busy, add only the measured Codex busy-blocker needed to prevent premature screen completion. Do not create a new compaction/resume protocol.
3. For the **raw `/status` parser**, first reproduce CUP and CUF joining with the actual `SubscriptionUsageParser.Parse` input. Narrow repair option: accept zero inter-word whitespace only within Codex's fixed weekly-limit/reset grammar after escape stripping, extract reset components and reconstruct the existing `HH:mm on d MMM` form before date parsing. This keeps the raw-buffer API, old plain/SGR behavior, Grok branch, percentage polarity, excerpt cap and malformed-date behavior. Do not globally replace/remove spaces in every provider parser, reinterpret arbitrary raw output as a current frame, or change shared `AnsiStripper`. If actual captures need stronger state reconstruction, update this footprint/verification before editing the queue/runtime; that expansion is not silently authorized by this small plan.
4. For raw **response fallback**, compare the captured echo/answer to expected text and questioning result. If cursor paint defeats echo removal or word spacing, add a Codex-only rendered-input fallback at the two existing adapter call sites, retaining the existing raw behavior for plain/SGR/hard-wrapped output. Feed the real current screen rather than replacing every escape with a space. Keep raw diagnostics unchanged and document that screen-only fallback is bounded by the visible screen; the rollout remains the source of a complete answer. Do not rewrite the global renderer or widen transcript delivery authority to make a screen test pass.
5. If JSONL dialect/field casing differs, add the smallest discriminator/field handling at `CodexTranscriptNormalizer`; retain old flat/thread-item, UUID, de-duplication, final-answer identity and error/timezone behavior. Preserve tailer ownership/C1-C4. A new version of `ModelLevelAliases` or a hold on an unknown model is not a parser repair; CARD-0903 owns that decision.

Rejected: speculative broad regexes for every modal; changing production timeouts to hide a mismatch; globally altering ANSI stripping; diagnosing a raw parser from an already rendered-only test; weakening stale-baseline or rollout ownership guards; changing hold writers/model ladder without a reproduced parser need.

### D-5: bounded tests and independent gate evidence

Replay tests call production code, use fixed timestamps/fake time and scripted runner snapshots, and do not spawn Codex. Do not add real-time assertion margins. Existing old timing tests remain visible as known hazards. Separate static source counts, runtime results, real CLI capture evidence and vendor-derived evidence. The operator's Final Review rule applies: fail for an existing-behavior regression or a new reachable fail-open/privacy exposure; missing required evidence is pending, not invented success. Test-strength work remains confined to these consumers.
