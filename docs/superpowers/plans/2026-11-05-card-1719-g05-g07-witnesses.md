## Implementation and verification design

V-1 / G05: the owner and busy snapshots see Failed. A real writer commits Blocked
before candidate SQL, then Failed after that SQL fixes its snapshot. Assert the
materialized candidate was Blocked, the database is Failed, and no release occurs.
This makes the local status guard independent of later fresh status/ownership checks.
A fresh sweep must release the otherwise eligible seat.

V-2 / G07 (Queued, Dispatched, Working, Blocked): seed an older open task on the
same agent/session while the newer Failed task remains the latest owner. Close the
older task after candidate SQL, leaving the busy snapshot occupied. Assert the
candidate is Failed and the older task is now Succeeded; no release this sweep,
one release next sweep. Closing before later open-task checks prevents masking.
