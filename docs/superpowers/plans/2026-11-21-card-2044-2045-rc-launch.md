- R-2. Run the touched and named integration classes, the matching committed impact rows and the standard guards. The nightly Unit lane is outside this round. The bounded affected classes below need one cold build and at most about 20 minutes excluding admission. No full assembly run.
- V-3. Check every edited PowerShell script for ASCII and parse errors, and inspect the changes for Windows PowerShell 5.1 syntax. Check the two documented launch inputs and verify that no new OS-specific production branch is required. The test covers the existing Linux detach path. Native Windows console detach remains separate from this task.
- R-3. Run the full task-range evidence diff and fetch master for the merge-tree check. Verify the index generator is stable after regeneration if it changes the committed index.

Candidate positive controls PC-1 through PC-3 cover removing the rc ReleaseRoot guard, omitting the refusal JSON field and discarding the supplied checkout root in each of the three scripts (PC-3 starter, supervisor and observer variants).
