# CARD-0989: pin the Grok CLI download by SHA-256

Date: 2026-10-12. Card: Antiphon `38e7ebb4-8265-46e5-9e12-3532606c4296`.
Inspected source: `d8188da496b2369e9ee688f8977c4888510fbb9f` (`runtime-base` still pipes `https://x.ai/cli/install.sh`).

## Decision

`docker/session-runner-grok/Dockerfile` `runtime-base` downloads `https://x.ai/cli/grok-${GROK_VERSION}-linux-x86_64` to a file, checks a reviewed SHA-256 with `sha256sum -c`, and only then installs and runs `grok --version`. The unchecked `install.sh` pipe is removed. There is no fallback to that script. This slice does not build or push an image and does not touch the server2 stack.

## Pin supply and rotation

The reviewed pair lives as ARG defaults inside `runtime-base`, same shape as Claude Code:

- `GROK_VERSION=1.0.41`
- `GROK_SHA256=9ce03ed23e16ea01072b4496263d6213a27899e1e3e107f008d36edf82e70407`

Measured 2026-10-12 without executing the download: `HEAD` of that URL returned `content-length: 165967424` (the size CARD-0989 recorded on 2026-10-02). The fetched file's SHA-256 is the value above, and the bytes match the host `/usr/local/bin/grok` that prints `grok 1.0.41 (4220f3b224a6) [stable]`. The temporary download was deleted after the hash.

A normal image build uses those defaults and needs no extra build-arg. Raising the pin means editing both defaults together after hashing the new raw artifact. A re-published file fails at `sha256sum -c`. The remedy is a new reviewed pair. Dropping the check or returning to `install.sh` is not a remedy.

An operator who must override the pair passes `--build-arg GROK_VERSION=<version>` and `--build-arg GROK_SHA256=<64 lowercase hex>`. An empty or non-64-hex `GROK_SHA256` fails the `RUN` before `curl`.

## Failure behaviour

In the same `runtime-base` `RUN`, in order:

1. `test -n "${GROK_SHA256}"` and a `^[0-9a-f]{64}$` check. Failure stops the build before any fetch.
2. `curl` writes the artifact to `/tmp/grok-download/grok` and does not execute it.
3. `echo "${GROK_SHA256}  /tmp/grok-download/grok" | sha256sum -c -`. Mismatch stops the build before `install` and before `grok --version`.
4. `install -m 0755` to `/usr/local/bin/grok`, `ln -sf grok /usr/local/bin/agent`, then `/usr/local/bin/grok --version | grep -F "${GROK_VERSION}"`.
5. `rm -rf /tmp/grok-download`.
