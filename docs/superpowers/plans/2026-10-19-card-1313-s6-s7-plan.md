Date: 2026-10-19. Stage: Plan. Target: **master only; the previous RC is closed**.

## Outcome and boundaries

Consume the landed selector and timing components through the release entrypoints,
first as Full execution with Shadow diagnostics, then as explicitly qualified
ChangeAware release coverage. Preserve CARD-1311's long-lived release line,
per-tested-SHA candidate roots, pre-release/final tags and moving-tip refusal.
Provide CARD-1281 a frozen aggregate selection adapter; its scheduler, admission,
landing, card projection and approval policy remain outside this increment.

The producer prerequisite remains real: production does not call
`New-ReleaseGateAuthority` or `New-ReleaseGateExecutionPlan`. S6 must include that
producer and its actual prepublication card receipt before reduced release credit
can ship. A harness that hand-writes a ledger is not that producer. Shadow and its
docs can land independently while this dependency is commissioned. This plan defines
the release-side input; CARD-1281/release coordination owns supplying the durable
intent and existing release card identity.

This Plan changes documentation only. No builds, tests, discovery, mutation checks,
card writes, dispatch, release, activation or deployment ran.

`BaselineSha`, `BaselineReceiptPath`, `QualificationPath`, `TimingRoot`, optional
`TrainManifestPath`, and `ReleaseIntentPath` for the producer below. Caller files
are validation inputs, never authority by themselves. Resolve an omitted baseline
only from verified Full publication records in configured durable release state.
No valid baseline means explicit Full fallback.

For reduced execution B must be an ancestor of A, with the same repository,
profile/platform and policy/catalog/selector/runtime contract. Unknown paths and

### Full producer prerequisite

`ReleaseIntentPath` is a versioned, create-once coordinator input containing
repository, intentId, releaseCardId, candidate id/ref/A and creation time. Validate
containment/no escaping links in release state and candidate identity. The existing
coordinator/caller supplies it; this card creates no server service or release card.
Legacy Full invocations without intent retain their existing missing-authority
publication refusal rather than silently manufacturing one.

S6-B binds the actual production sequence:

1. Validate intent/candidate and call `New-ReleaseGateAuthority` once.
2. Discover the complete candidate profile (expanded native UIDs and client/script
   entries) with source/build identity before execution; freeze discovery and plan.
3. Run the frozen plan through existing process ownership, slot and native locks.
   Persist actual prerequisite/chunk/roster terminals, TRX/digests/counts and teardown.
4. Persist report intent after terminal ledger; update the **bound card** through
   existing HTTP/card operations. GET full body/current revision independently;
   construct the existing typed prepublication receipt only after exact correlation.
5. Persist receipt; the current-candidate publisher rechecks the live card and remote tip.

Retain one logical report identity after failed write, unavailable/conflicting
recipient or lost response after recipient commit. Recover from persisted intent,
with fresh concurrency tokens and unrelated card content preserved. Existing whole
correlation means readback, not a duplicate report. A conflicting newer revision
cannot be overwritten or accepted as the old receipt. No queue or session-input
path is introduced; synchronous HTTP and durable local intent suffice.

Before commissioning S6-B, the caller binds who supplies intent and existing card;
TestDesign must prove its fixture invokes that entrypoint. The expected shape is
not a claim that CARD-1281 already supplies it. If the owner is unavailable, S6-A
and accurate Shadow docs can proceed; S6-B/C/D stay unready. Do not call S6 complete
or request activation with that dependency outstanding.

### Scoped authority, baseline and public credit

V2 binds scope, full discovery, selected UID/entry union, omitted UID/entry digest
and reasons, exclusions, B/A, baseline/qualification and optional train membership.
Client/scripts keep full declared rosters unless the catalog explicitly validates
entry-level selection; neither becomes an empty omitted suite accidentally.

Publisher recomputes selection from pinned Git objects, checks executing selector
bytes against the pinned implementation, and reconstructs the partition from full
candidate discovery. Repairing caller hashes cannot legitimize an edited omission.
Every UID has exactly one disposition. Selected UIDs execute exactly once per
attempt, including all data rows; failed/skipped/missing/extra/duplicate/zero required
results refuse. Live/manual/other-OS obligations remain visible, never passed by omission.

Full/Shadow stay `coverageScope=Full`, with `allProfileCasesExecuted=true` only after
complete execution and ordinary Full credit. Selected green has
`coverageScope=ChangeAware`, `selectionComplete=true`, `coverageComplete=false`, and
`allProfileCasesExecuted=false` whenever anything is omitted. Store a distinct
selected-green record; an explicit v2 scope-aware RC credit/publisher path consumes
it. Identity/booleans alone cannot earn selected credit. Full-only readers and master
readiness files never receive selected green. NoReport, diagnostic and seam-driven
production runs still cannot publish; unknown schemas/scopes refuse.

Historical B validation uses immutable archived Full authority, execution ledger,
receipt and confirmed-publication digests. It does not apply current-card-revision
or remote-tip checks to the historical release. Keep both checks for candidate A.
Selected, master-readiness, legacy-unqualified, foreign-repository or wrong-platform
receipts cannot seed reduction. Legitimately incompatible policy/runtime selects
Full; malformed/digest-mismatched or contradictory claimed identity refuses.

Activation is an explicit configured reference to an immutable qualification record
under durable release state. Bind repository, policy/catalog/selector/coordinator/
publisher/runtime contract, Full and paired Shadow evidence digests, Review identity
and activation revision/authority. Selection never approves itself. Missing/revoked/
incompatible qualification forces Full before execution; corrupt claimed records
refuse. No activation or scheduling command is added here.

Manifest v2 adds only scope, B/A, selection/omission digests/counts, qualification/
baseline digests and optional train digest to existing allowlisted fields. Internal
hosts, absolute roots, raw timing/logs and card bodies stay private. Tags, promotion,
reservation and `remote-candidate-moved` stay unchanged. V1's existing six-file script
hash contract remains historical; v2 additionally binds selector/catalog and all new
producer/consumer helpers and entrypoints, without hashing a moving branch tip.

### Timing producer and estimates

Pass actual run/attempt/candidate identity into roster execution. Event IDs derive
from run/attempt/set/chunk and are globally distinct, stable on recovery. Measure
monotonic wall around the owned child and finish after join. Use actual TRX/discovery
for counts, class/category windows and expanded UID/assembly joins. Include repository,
SHA, host/OS/architecture/runtime/concurrency/profile/membership/producing-build identity.
Unknown values stay null with reasons; overlapping case durations are not wall time.

Use the landed durable journal contract (flush/spool/replay), with one producer per
logical event. The current PowerShell `AppendAllText` hook is not evidence of that
contract: bring that adapter to parity with the named tests or expose the existing
local writer through a bounded adapter. No timing service or unrelated checkpoint
rewrite. Persistence failure records incomplete timing and recoverable data; it
never changes a test result or selected membership. It blocks timing/rollout
acceptance, not by rewriting passing tests as failures.

Filter estimates by the complete `Get-TestTimingReport` comparability key before
attachment; first matching setId alone is insufficient. Missing estimates stay
unbudgeted. Fresh-reader query after output cleanup proves persistence. Count a
producing build once; do not add class/category overlap to roster wall. Retain old
incomplete observations without inventing missing measurements.

### Train adapter and rollout

`Resolve-ReleaseTrainSelection` in the new helper accepts versioned external
repository/target ref B/aggregate ref A/member SHAs and patch identities/canonical
membership digest. It returns selection identity and unresolved obligations for
CARD-1281 to store. It reads Git objects and writes no task, approval, branch or card.
Compute B..A including integration edits. Bind the whole manifest: changed B/A/
membership invalidates the attempt. A changed target/rebased aggregate needs fresh
candidate evidence. No Full baseline at B means Full, even if an older baseline
exists elsewhere. Failed-candidate recomposition forces Full. The adapter cannot
authorize pre-land tags; exact aggregate Review, target publication and member links
remain CARD-1281 obligations. Do not bypass release-cut's long-lived RC admission.

S7 documents capability at each landed slice, schema-3 nine-suite profile, mode/
fallback/intent/root inputs, timing report commands and activation/rollback evidence.
Append a short supersession link to CARD-1281's hook section without rewriting
history or its failed-aggregate Full rule. Keep Windmill definitions disabled; future
configuration supplies explicit current ref, intent and durable roots. No hard-coded
RC date, fleet location, new cron, provider credentials or live-test flags.

Qualification is a separately commissioned operation after Code/Review/land: fresh
Full baseline and paired Shadow candidates for provider-only, shared-native, client,
linked-fixture and unknown paths, exact UID partitions and durable timing readback.
Measure fallback rate, wall/counts and failed attempts. Unexplained omissions revoke
qualification; rollback is Full, retaining history. No speedup is promised from the
historical Unit timings. Original platform and mutation obligations remain pending.

No new session waits for input. Missing qualification/intent settles with persisted
fallback/incomplete state. Existing waiting sessions retain seats while parking is
disabled, with **no automatic release deadline** (CARD-1083).
