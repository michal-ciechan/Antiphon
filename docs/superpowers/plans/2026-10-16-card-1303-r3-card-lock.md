Change only AgentTaskService's card admission lock to FOR NO KEY UPDATE. Preserve
transaction lifetime, ordering, re-read and refusal semantics. Teach existing SQL
observers to recognize both lock modes; independent NOWAIT probes retain the real lock checks.

The current delegated AgentTaskDispatcher creates sessions with CardId=null.
OrchestratorService.TryClaimCardAsync is the actual card-bound claim: it inserts
AgentSession, then updates Cards. R3 promises the insert can complete while create
holds admission. The later card UPDATE must still serialize. No existing test at
this base asserts a blocked claim insert; retain the existing close/create fence
and add its complementary insert witness in the same integration class.

S1 commits the regression and observer adaptations before changing production.
S2 changes the one lock mode, after CP-1 proves the guarded defect.
No deliberate mutants in Code; SourceLanding Mutation owns the pending controls.
