### Delivery inventory

S1–S3 synchronously pass a versioned compiler manifest, release relation and proposed partition to the next reader. Open the persisted bytes at each reader and inspect its returned binding/selection. In S4 the replay, Full shadow and pilot/backstop scorer write the same miss format. Reopen the immutable record and its referenced evidence from a fresh consumer, then read the gate's disposition at the same revision. An in-memory miss list is insufficient. Diagnose/repair card handling is an RC operator workflow under CARD-1781. The test reads the actual selection instructions and links in the repair fixture. These changes introduce no agent session input.

S5 has a delivery obligation. A withdrawn qualification attempt produces a distinct Full at the **same SHA**. The destination is the qualification dispatcher and ultimately the chunk executor. Persist withdrawal, incomplete attempt, taint and the obligation for a replacement Full before allowing coverage credit. Join recovery and recipient evidence by candidate SHA, approval revision, old and new attempt identities, roster digest and chunk content/case identity. Use the real commissioned qualification scheduling path and its real dispatch queue if queued. Run the producer with the recipient already eligible, with the execution seat held until a deterministic barrier releases it, and with failure between durable withdrawal and scheduling, including an enqueue failure/restart. Re-open persisted state with fresh instances. Each trace must end with one logical replacement attempt, all fixture recipients actually invoked, their fresh case results read back, no lost obligation or double credit (G-49–G-52 below). If recovery uses synchronous scheduling, interrupt the equivalent call boundary and drive the normal retry. The current in-process dispatch loop itself has no durable enqueue acknowledgement.

Only native test execution and remote publishing may be substituted at this boundary. The fake **leaf** executor receives the real scheduled case list, records the invocation and writes a per-case TRX keyed to the new attempt. It can deliberately omit one case. Scheduling a Full, a journal row, a publisher invocation or an enqueued request alone earns zero receipt credit. If the CARD-1836 post-discovery/Full scheduling path cannot be driven, S5 stays pending that integration. Keep production Full and return the seam to Plan rather than verifying a disconnected executor.

### Compiler inputs and literal resolution oracles

Use one checked fixture input pack, compiled once per host as deterministic in-memory libraries. Keep it outside the scanned source universe (inline text or non-`.cs` fixture data). The positive authority is a separately frozen build/input manifest. The producer must open its specified bytes. Creating expected bindings by asking either Roslyn or the production graph which edges survive would make the test circular. Compilation diagnostics establish fixture reachability only. A positive with any error fails setup. For error twins require the intended error at the named token, or the specified missing input at custody verification.
