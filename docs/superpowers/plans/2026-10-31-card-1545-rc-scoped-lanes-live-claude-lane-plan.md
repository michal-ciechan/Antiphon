# Scoped RC lanes, starting with live Claude

Plan task e86e7d7a; source inspected: cbe3e6b42401db766f4cee38bc9b34f5b9d314af, 2026-10-31.
CARD-1545 is the existing scoped-RC workstream, not a newly allocated card.
This filename follows the mandatory card-number plan convention; this is the single plan deliverable.
Status: proposed under D-1 through D-10 below. No implementation, release policy, test selection, credentials or running qualification was changed.

Build a separately commissioned, serial live-Claude lane with exact test membership and its own receipts. Keep ordinary Full RC and master readiness intact. Start with five core results, inventory the remaining manual obligations, then add content fingerprints and an additive candidate gate. A fingerprint proves equality of captured inputs; it cannot prove that an unversioned remote model or service has not changed.

This plan was prepared from repository files only, plus the required read-only placement APIs. No desktop filesystem, native test, live provider, browser, deployment or credential store was accessed. The brief's d47848cc run duration (15+ hours / 450+ chunks) is caller context, not a timing receipt inspected here.
