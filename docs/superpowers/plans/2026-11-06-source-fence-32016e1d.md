before target observation processing, fetch/pinning, ancestry judgment or publication. Preserve
the one-advertisement optimization introduced by `d71a4d60fdb1e32ed49e7c6486d2fc49e453a885`:
read source and target refs together, validate the source, run the fence, then process the target.

Keep the original overload for callers without a fence. Do not edit `ControlledLandingGit.cs`.

tests exercise accepted/refused fences through both combined and fallback reads and ensure remote
