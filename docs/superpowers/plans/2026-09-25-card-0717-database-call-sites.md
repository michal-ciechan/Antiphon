# CARD-0717 database call-site source census

Companion to [the resilience plan](2026-09-25-card-0717-polly-resilience-plan.md), against origin/master `39444f915fc104f71b49e2a7a4d269f08d59e8f1` (2026-09-25). Documentation only.

This is the conservative source index for the staged rollout, not a global retry allowlist. The main plan owns exact HTTP classifications, all explicit transactions, the raw startup Npgsql connection, health checks, and the four admitted R1 DTO getters. It also owns the S/K/N meanings. **N** here means do not generically replay this site in its current enclosing operation; extraction into a pure materialized read can create a separately reviewed **S** boundary. **K** writes need a durable operation identity, expected-version contract and unknown-commit verification. **N** writes remain with their existing effect/evidence owner. Any broader promotion must update the row with the new unit and test evidence; a read's presence in this index is not approval to replay its entire parent method.

The deterministic scan covers production `server/` and `src/Antiphon.Messaging.Service/` C# files referencing AppDbContext, MessagingDbContext or EF Core, excluding bin/obj/migrations and comment-only lines. It indexes async EF-style terminal operations, raw SQL/query construction, persistence and synchronous LINQ-shaped candidates. Synchronous candidates can be in-memory LINQ; they are included for review, **not** misrepresented as proven database round trips. FromSql/SqlQuery occurrences are construction, with execution at a later terminal operator. Helpers can make one source occurrence execute many times. These counts are source locations, never test counts or proof of coverage.

208 files; 1893 read/query-construction lines; 644 write/raw-command/startup lines; 1396 synchronous candidates. Multiple kinds can occur on one line. Transaction locations are separately enumerated and classified in the main plan.
