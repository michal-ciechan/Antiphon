## Decisions

- **D-1 — conservative capture-site unknown (default).** When a non-invoked expression captures a recognized reflective load/invoke callable, record `reflection-target-unresolved:<caller source path>` immediately. Reuse receiver expansion, aliases, qualification and nullable/parenthesis peeling. Cover variable/field initializers, assignments, and argument/return expressions where a method group is passed or escapes. A reflective callable inside a lambda or local-function body must reach the same classification. The reason belongs to the source containing the capture; a target's or delegate consumer's reason cannot replace it. Direct invocations keep their existing handling. Reject whole-program delegate propagation/semantic compilation: the source-only graph has no evaluated references and cannot prove those flows complete. Capturing already marks the uncertainty without tracking every later copy.
- **D-2 — normalize generic invocation syntax (default).** Add bare `GenericNameSyntax` handling before consulting static usings; retain the existing conservative reflective-static-using behavior and parameterless ordinary `GetType()` exception. Reject a text search for `CreateInstance<`: syntax must distinguish code from comments/strings and preserve ordinary call behavior.
- **D-3 — exact inherited scope (default).** Four new independently named methods and four method-scoped checkpoints are mandatory. Small variants inside each method may prove the same capture without invocation and a harmless delegate control; they do not count as extra executed tests. Existing lambda/local-function and alias/constant-binding behavior stays under the regression contract. Reject expanding this card into a claim to recognize every reflection API or to remove inherited false positives.
- **D-4 — preserve all safety fences (default).** New reasons are additive and deduplicated by the existing `SortedSet`; a dynamic capture never invents a target edge. Preserve positive constant `Type.GetType`/`Assembly.Load` edges, old/new union, project closure and unrelated callers. Doubtful binding stays unresolved/Full. Reject suppressing a reason because a syntactic edge or declaration happens to exist.
- **D-5 — serialize future implementation (default).** Code owns `tests/Antiphon.Tests/Scripts/ReleaseImpactProjectGraph.cs` and `tests/Antiphon.Tests/Scripts/ReleaseImpactProjectTests.cs`; these collide with later selector/S1R6 project-closure work. Generated `tests/derived-impact-index.json` is also shared with CARD-1836/CARD-1820. The caller must wait for selector scope and dispatch from fresh landed master. Do not merge an in-flight sibling or hand-edit the generated index. Plan review can proceed now.
- **D-6 — portable placement (default).** GET `/api/runner-defaults` and GET `/api/session-runners` succeeded during planning: revision 2 had a usable global default; the catalogue had eligible Linux and Windows lanes, plus a retired ineligible entry. Resolve placement again at dispatch. All checkpoints below name the portable Unit lane, runnable on Linux; omit `-Runner` and `-Platform` unless a subsequent task actually needs a pinned host/OS. No fleet address is an implementation input. Existing native acceptance elsewhere remains owed.
- **D-7 — stage and waiver (default).** This artifact includes verification design because the commission freezes witnesses and checkpoints together. Next is the caller-requested **plan-review**; after acceptance, Code can execute it without a separate generic TestDesign pass. Standing operator authority covers the task-branch publication; no further go-ahead is needed. Mutation checks remain waived (operator 2026-11-12); no PC is claimed. Ordinary committed assertion-red evidence is still required.

## Verification design

Every new witness uses one C# caller at **`tests/Consumer/Reflection.cs`**, a consumer project with **no ProjectReference**, and a product assembly named `Fixture.Product` with a `Product.Queue` declaration. The caller is `Example.ReflectionTests`; each method receives a fresh input dictionary. Use valid parseable source and assert the actual syntax shape (a method-group value, not an invocation, for V-1..3; `GenericNameSyntax` for V-4). No actual fixture assembly is loaded or executed.

For every main input, assert exactly one `reflection-target-unresolved:tests/Consumer/Reflection.cs`, `Complete == false`, `Fallback == "Full"`, and retention of `project-evaluation-unavailable` plus `assembly-metadata-unavailable`. The exact path assertion is the acceptance oracle; global reasons or unrelated edges cannot substitute. The method's reason assertion must fail before any secondary expectation can mask the red cause.

| ID / exact new method in `ReleaseImpactProjectTests` | Frozen original form (inside `namespace Example` / `ReflectionTests`) | Independent oracle and bounded control |
|---|---|---|
| V-1 / `DelegateBoundAssemblyLoadLocalFailsClosed` | `using System.Reflection;` then `object Read(string name) { System.Func<string,Assembly> f = Assembly.Load; return f(name); }` | Exact caller unknown. A second tiny input removes the invocation, retaining the capture: still unknown. A harmless ordinary delegate capture in a third input must not add this reason. |
| V-2 / `DelegateBoundAssemblyLoadFieldFailsClosed` | `using System.Reflection;` then `System.Func<string,Assembly> f = Assembly.Load; object Read(string name) => f(name);` | Exact caller unknown. Remove `Read` while keeping the field initializer: still unknown. A nonreflective field-delegate control has no reflection-path reason. |
| V-3 / `DelegateBoundAssemblyLoadCastVarFailsClosed` | `using System.Reflection;` then `object Read(byte[] bytes) { var f = (System.Func<byte[],Assembly>)Assembly.Load; return f(bytes); }` | Exact caller unknown despite `var`, cast and overloaded method group. Remove the call but keep the capture: still unknown. An ordinary cast delegate control has no reason. |
| V-4 / `BareStaticUsingGenericActivatorFailsClosed` | `using static System.Activator;` then `object Read<T>() => CreateInstance<T>();` | Exact caller unknown with no string argument. Qualified `System.Activator.CreateInstance<T>()` remains unknown as the paired control; ordinary `new object().GetType()` without the static using must not acquire the reflection-path reason. |

Existing `ReflectionIsBoundOrUnknown` protects known literal target binding and unresolved target fallback; alias, conditional, native-loader, union and Update/Remove methods must also remain green. Preserve lambda/local-function direct-call behavior by inspection and the shared invocation path; this card does not mislabel those already-passing examples as newly failing witnesses.
