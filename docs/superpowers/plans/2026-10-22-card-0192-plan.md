# CARD-0192 Herdr: adopt a hand-made pane - plan (recommend close: delivered by CARD-0213)

**Outcome.** CARD-0192 asks for nothing that master lacks. CARD-0213 ("Herdr: attach/adopt an
existing operator pane instead of launching a duplicate", Done, shipped `22a0d14`) built option (b)
from CARD-0183 end to end: server route, runner inspect and bind, attached-origin sidecar, detach-on-stop,
restart re-adoption, and the UI modal. CARD-0192 was written from CARD-0183's investigation before
CARD-0213 landed. Its text ("`AdoptHerdrSessionsAsync` only ever re-binds sidecars this runner itself
wrote", "`HerdrLaunchOptions` carries no pane-id field") is out of date. **Recommendation: close
CARD-0192 as a duplicate of CARD-0213. No code slices.** The only unbuilt piece is a pane picker,
which `docs/herdr-sessions.md` §3a names as an optional follow-up. It is not this card's ask, and
nothing shows anyone wants it (see D-2).

No source edits. No migration. No rc work: this is not a defect.

## Safety rules, and where each is held today

| Rule | Held by | Witness |
|---|---|---|
| A transcript-confirmed UserPrompt is the only delivery verdict | The attached session is an ordinary Herdr session row. The transcript tailer comes from the kind (Claude/Grok/Codex). Grok without a resolvable native id, or without a `GROK_HOME/sessions/*/{id}/` directory, is refused (`herdr_native_id_unknown`, `herdr_transcript_not_found`), so a session cannot exist without a transcript to confirm against | `HerdrAttachTests.Grok_without_session_id_is_refused`, `Grok_with_no_session_directory_is_refused` |
| A process release leaves the process killed, pooled warm, or owned by a standing agent. A hand-made pane is never killed by pool release | Every kill site detaches an attached origin. The process stays with its human owner and is never killed | `HerdrAttachTests.Attached_kill_detaches`, `Attached_orphan_is_dropped_not_killed`; `AgentAttachHerdrTests.Stop_on_an_attached_agent_leaves_the_pane_process_alive`; `HerdrPaneDisposalStopRegressionTests.C461_G053..G061` |
| A pool delegate attached to a pane is never reused for a task on a guessed provider stamp | CARD-0167 S3: attaching a pool row stamps `PoolProviderProjectionJson = UnknownPoolProjection`, which matches no task | `AgentAttachHerdrTests.C0167_attaching_a_pool_delegate_marks_its_provider_projection_unknown` (and CARD-1495 reuse witnesses) |
| Workspace reservation belongs to the adopted session and is released on refusal or failure | CARD-0664 A8/D-4/D-6 in `AttachHerdrAsync` | `AgentAttachHerdrTests.C664_*` |

## Decisions

- **D-1 Close CARD-0192 as delivered by CARD-0213.** Reason: every point in the card's Scope sketch
  (ownership, kill semantics, where the pane id lives, restart adoption) has a shipped answer and a
  named test on master. Rejected: re-implementing or "hardening" attach under this card. That would
  duplicate a Done card and its review history, and no defect has been shown.
- **D-2 Do not build the pane picker under this card, and do not file it by default.** Reason: the
  card says it was filed "so the idea isn't lost, not because it's known to be wanted". Attach by a
  typed pane id works, and operators already address panes as `wN:pM`. Rejected: building
  `GET /herdr/panes` (runner list route, server proxy, `Select` in the attach modal, about 2 slices)
  now. If the operator wants it, file it as its own enhancement card. The sketch: S1 is a runner
  `GET /herdr/panes` that lists panes with `agent`, `boundToSessionId`, and a single-foreground flag
  from the existing inspect projection, with no raw argv, env or cwd, plus a server proxy. S2 is a
  modal `Select` that hides bound or unsupported panes and keeps the free-text id.
- **D-3 Attach by pool delegates stays as it is.** The code admits `IsPoolDelegate` rows. This is
  safe: release detaches, the provider stamp is `unknown`, and the row is never reused for a task.
  Tightening it to standing-only would be a behaviour change, and no card asks for one. Recorded
  here so a reader does not mistake it for a gap.

Not applicable. This plan adds and changes no session that waits for input. An attached session

no automatic release deadline (CARD-1083). Stop detaches.
