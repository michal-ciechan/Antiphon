## Decisions

- **D-1 — Global stable priority.** Prepare the same complete suite plans once, flatten references in existing suite/chunk order, stable-partition references into priority and ordinary work, then execute serially. All chunks intersecting a listed class precede every ordinary chunk across all suites. Within each partition retain old order. Reject per-suite sorting because session-runner, agents-pty and E2E failures would remain behind ordinary antiphon work (`:1174`, `:1319`). Reject repricing or repacking Full: it changes grouping, timing strata and ledger obligations.
- **D-2 — Immutable Full plan, separate schedule.** `antiphon-nightly-dispatch-v1` records `(suite, chunk, canonicalOrdinal, dispatchOrdinal, priorFailure)` plus history digest and canonical plan digest. Never renumber IDs or reorder an already sealed authority document. No history means the existing dispatch order. Full canonical plan, membership, exclusion census, filters, cost/watchdog fields and ledger row identities remain unchanged. Schedule is diagnostic and grants no authority.
- **D-3 — Class-level selection.** Input is suite + fully qualified bare class identity, using `Get-NightlyBareClassIdentity` for constructor display suffixes. No method selectors, globs, prefixes, display names or manual aliases. Every required expansion and split of a matching class is selected. Full prioritizes whole existing chunks, including their other classes. Partial replans only selected classes using the same production planner and full discovery universe for prefix-collision safety; it does not drag unrelated co-packed classes into the sweep. Exclusions remain effective in both modes.
- **D-4 — Versioned failure-history JSON.** Add `scripts/export-nightly-prior-failures.ps1` and `scripts/lib/nightly-failure-history.ps1`. The explicit exporter runs on a closed retained run directory and writes a new immutable file outside that run. It reads existing TRX, summary, pinned diagnostic evidence and per-suite planned/discovery artifacts. It does not scrape Markdown investigation tables or consult live services. History is a scheduling hint, never a receipt. See its exact schema and fallback below.
- **D-5 — Missing TRX means whole prior chunk.** Include all classes from the bound historical planned chunk when TRX is missing/malformed, diagnostics are truncated/ambiguous, summary marks timeout/nonzero exit without accountable failures, or required UID evidence is incomplete. Record fallback reasons, including diagnostics found. If that chunk's exact class membership cannot be reconstructed from its bound per-suite plan/discovery, exporter refuses with no usable output. Reject a TRX-only best-effort list: it loses seven errors and a hang. This deliberately includes potentially passing classes from an incomplete chunk, but does not turn all historical platform skips into failures.
- **D-6 — Resolve history against current discovery, fail closed.** Deduplicate ordinally by suite/bare-class; reject duplicate conflicting provenance, unsupported suites/versions, incomplete source identity, missing members, zero resolved required UIDs and classes now entirely excluded. Emit a resolution report naming the mismatch; no silent dropping or fuzzy renames. Operator regenerates evidence or commissions an explicit reviewed mapping in a later task. Do not add an override flag in these slices. An empty validated list is permitted for Full (no-op); Partial refuses it. The previous run SHA may differ from the candidate; both are bound and retained, and previous binaries/results are never execution evidence for the new SHA.
- **D-7 — Two orthogonal controls.** Add `-PriorFailuresPath` and receiving-hop `-PriorFailuresDigest`, plus `-QualificationMode Full|PriorFailureSweep` (default Full), to `nightly-run.ps1`, both wrapper/implementation parameter blocks in `nightly-run-impl.ps1`, `nightly-tests.ps1` and `Invoke-AntiphonNightlyTests`. Reject sweep with release intent, selection-attempt, baseline receipt, train manifest or publication authority arguments; it gets a diagnostic selection document, never a Full selection attempt. Read/copy/hash history into the owned new run before sync; self-reexec and executor verify the copied bytes/digest, including -NoSync.
