## Ground truth

`MechanicalPcContractTests.C479_V07_ActiveRecipesRouteBindingHighAndExecutionLow` is the
CARD-0479 plan's V-7 row ([plan](2026-09-10-card-0479-mechanical-pc-eligibility-plan.md)):
"active recipes route binding/adequacy at explicit Frontier and eligible execution at Low".
Commit `40eaeb89f` added one sentence to each active recipe:

> Commission binding-only at explicit Frontier, then eligible mechanical-execution at Low; one open Mutation per O.

The test asserted four free words anywhere in each file (`binding-only`, `eligible`,
`mechanical-execution`, `one open Mutation per O`).

| File | State at the task base |
|---|---|
| `docs/orchestration-loop.md` (Tiers section, paragraph opening `Code owns implementation and ordinary V/R;`) | whole sentence present |
| `.claude/skills/antiphon-delegate/SKILL.md` (alone under the role table) | whole sentence present; its only `eligible` |
| `server/Bundles/README.md` (`Default workflow:` paragraph) | whole sentence present; an unrelated `eligible` on the relaunch row |
| `server/Bundles/orchestrator.md` (`Default workflow:` paragraph) | CARD-1332 (`6ec71d427`) shortened it to `binding-only mechanical-execution; one open Mutation per O.`; the file's only `eligible` is the runner-placement line, which CARD-1332 kept so the free-word test stayed green |

So the bundle's routing words (explicit Frontier, Low, eligible) left the bundle without the
test noticing. The CARD-1332 plan and test design never named this sentence; the shortening was a
Code-stage edit, flagged by that task as CARD-1355.

## Decision

Pin each recipe's rule where it lives, by its own text:

- Owner, delegate skill and README: the whole sentence, paragraph-scoped (owner and README) or
  counted once (skill), plus the existing Mutation tier-row and contract-link checks.
- Orchestrator bundle: the exact shortened fragment and the owner pointer
  `Follow the full CARD-0478 recipe in docs/orchestration-loop.md.` inside the same paragraph,
  and the owner carrying the whole sentence the pointer resolves to. The runner-placement
  `eligible` is not consulted.

The missing tier words in the bundle are reported, not reinstated: restoring the 54 extra units
fits the 11,500-unit body allocation (measured 10,822) but moves the raw bundle pin and the argv
fixture, which is a separate card.
