series of isolated host fixtures and execute the production shell path for each
fault vector. Their fixture records distinguish setup, Bash execution and
disposal. The host fixture already shares its compose seed at test-session scope.

The replacement keeps all 64 other classes and all 229 current methods of
`RemoteScriptContractTests`. Known expensive methods have their own row.
Two methods whose names prefix other test names also use exact filters to avoid
duplicate execution. The remaining methods are grouped using the larger
published October and November measurements where present. For methods without
a sample the packing estimate is 10 s when they use the process limiter and
1 s otherwise. These are provisional packing estimates, not p95 values.
The group estimate sums case time because the process limiter can serialize
test bodies. Row deadlines use the checkpoint tool's estimate-derived limits
and record build and slot waits separately. Use the resulting per-test and phase
timings to revise the packing estimates before qualifying this selection again.
