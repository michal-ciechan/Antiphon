## Selector

It returns one tracked `SessionRuntimeAction` or none. `QueuePhase` is 8 and `ChannelReplyDebt` is `channel`, passed as parameters. `now` is `clock.GetUtcNow().UtcDateTime` as `timestamptz`, not database `now()`. Due channel rows use `<=`, so a row due at the injected instant is eligible. Non-channel rows are not due-filtered; the coordinator's existing future-row return remains.

The destination set is the non-null carried key plus non-null conversation keys of this session's late-confirmed messages. An earlier channel blocks on `IS NULL` carried key (either side) or on destination overlap. Same sequence does not block (`<`). Empty or null late arrays add no keys. Foreign and missing message ids add no keys. Non-channel rows are not blockers. Tie-break is phase flag, sequence, trigger kind. `(AgentSessionId, Sequence, TriggerKind)` is unique, so that order is deterministic for stored rows.
