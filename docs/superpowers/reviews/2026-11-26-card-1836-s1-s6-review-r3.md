## The author's reading of D-8 (present `owed: {}` stays admissible)

Sound. `owed` has exactly one producer, `RcComparisonBaseline.Choose` (latest row per content digest among ancestor attempts completed after the baseline, partial ones included; any non-clean row is owed), and one writer, `Record`, which computes `owedDigest` from the same object it serializes. The digest is therefore **not** independent of the producer: it detects a torn, hand-edited or pre-r2 file (now tested), not a producer that computed the wrong set. A correct empty set and a wrongly-empty one are byte-identical, so no admission rule can tell them apart without re-deriving the set from the attempts; refusing `{}` would refuse the normal no-later-failure state and turn Incremental off. The defence against a wrongly-empty set belongs at the producer, and it is now witnessed there (R3, R4) and at the consumer (R2). `Choose` and `Record` have no production caller yet.

Advisory **A-11** (for the wiring card, not this land): the remaining way to get a present, digest-valid, wrongly-empty `owed` is an input census that never hands `Choose` a later attempt (a crashed attempt with no receipt, a missing `Ancestor`/`CompletedUtc`). The wiring card must prove every later attempt directory at or after the baseline reaches `Choose`, including crashed and unsealed ones.
