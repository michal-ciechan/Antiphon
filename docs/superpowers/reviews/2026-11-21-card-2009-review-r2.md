### D-1 (still open, regression). C# verbatim strings make the new scanner skip E2E tests, and the fail-closed counter skips them too.

- **Where:** `scripts/lib/rc-input-manifest.ps1` `Skip-RcNonCode` (lines 534-542). It treats `@"` and `$@"` as running to the next `"@`, which is PowerShell here-string syntax. A C# verbatim string ends at a `"` that is not followed by another `"`. `Get-RcTestIdentityParse` counts `testAttributes` and `argumentOpeners` inside that same scan, so `Test-RcTestIdentityIncomplete` cannot see what the scanner skipped.
- **Failure:** On the real tree, a single `@"..."` in a test body skips the rest of the file, up to EOF or a later `"@`:
  - `tests/Antiphon.E2E/BoardE2ETests.cs` has 10 `[Test]` attributes. The parser sees 3 (`matched=3 testAttributes=3`), because line 214 `new Regex(@"^Session 1 - ")` hides the 7 tests after it.
  - `tests/Antiphon.E2E/ContractSnapshotTests.cs` has 5 and the parser sees 2 (`@"C:\src\antiphon"` at line 197).
  - Across the E2E tree, 143 `[Test]` attributes are present and 133 are matched. 10 E2E tests have no identity, and the file is not flagged incomplete.
  - Real selector function, scratch git repo, real `BoardE2ETests.cs` with `Board_running_session_shows_stop_button` renamed: `Test-RcTestIdentityChange` returns **True at base `30e42ec5`** and **False at tip `adc423c4`**. The rename now defers. Base selected it.
- **Why:** The fix claims the parser fails closed. Instead it adds a fail-open path that is live on the current E2E tree, and the round-1 base did not have it (round 1 measured every E2E `[Test]` parsed at `30e42ec5`). Round-2 scope covers regressions. Shadow mode lowers the cost, but this is the FALSE-SKIP the card exists to remove.
- **Adequacy (same function):** Mutant M1 makes `Test-RcTestIdentityIncomplete` always return `$false`. `E2EIdentityChangeSelectsSuites` stays **PASS** under it. All three new witnesses are also caught by the structural parse, so no test witnesses the fail-closed rule, which is the core of the claim.
- **Also fix in the same pass (latent):** In the comma-list form `[Test, Arguments(1)]`, `argumentOpeners` counts only `\[Arguments\(`. Adding `, Arguments(2)` therefore defers (probe: `defer`). E2E has 0 uses today. `tests/Antiphon.Tests` has 79, for example `TurnEndGapRestartDeliveryTests.cs:21`.
- **Fix:**
  1. Implement C# verbatim rules: `@"`, `$@"` and `@$"` end at `"` that is not followed by `"`, with `""` as the escape and no backslash escapes.
  2. Count `testAttributes` and `argumentOpeners` independently of the scanner. For example, use a regex over `Get-RcCommentStrippedText`, so that a scanner skip shows as `testAttributes > matched`.
  3. Count `Arguments(` openers inside comma-separated attribute lists. Capture them as rows.
  4. Add witnesses: (a) a rename after a verbatim string, red at `adc423c4`; (b) a case that only the fail-closed rule selects, red under M1; (c) a real-tree check that every `tests/Antiphon.E2E/**/*.cs` has matched == the regex `[Test` count.
