1. **An explicit blank selects the default checkout.** The [entry point](../../../scripts/qualification/stop-supervisor.ps1) says the default applies when the argument is omitted. Line 37 applies it to every null, empty or whitespace-only value. On a linked checkout, both an empty string and three spaces printed the dry run (exit 2) and reached the Linux confirmation path (exit 5). All four calls should have exited 6 before import. An empty checkout field in an operator command therefore admits the entry point's checkout. Use parameter binding to distinguish omission from a supplied blank and test both inputs from inside a valid checkout.
2. **The refusal test loses the output channel and misses both helper checks.** At [test-qualification-stop.ps1](../../../scripts/test-qualification-stop.ps1) line 634, the harness merges the child streams under `$ErrorActionPreference = 'Stop'`. A refusal written to stdout would satisfy its assertion. On Windows PowerShell 5.1 the expected stderr write can also raise a terminating native-command error before the assertion reads the exit code. This is a compatibility finding from inspection. Capture the child's stdout, stderr and exit code separately. Assert empty stdout and one refusal on stderr. Include a checkout with each required helper absent in turn. All six existing cases exit before the helper-presence loop, so removing either check leaves them green.
